# 교실에서 2~3명이 함께하기

개인 탐사 기록은 각 브라우저에 저장한다. 공동 균형 실험은 방 서버의 메모리에만 남고, 마지막 참가자가 나가거나 연결이 만료되면 종료된다. 별도 계정은 필요 없다.

## 교사 PC에서 실행

2026-10-21 사용자 결정으로 **같은 교실 네트워크**에서 접속하는 방식을 사용한다. 공개 웹 서버나 별도 계정은 필요 없다.

프로젝트 폴더의 **`교실서버.cmd`를 더블클릭**한다. Node.js가 설치된 교사 PC에서 실행하며, 창에 표시되는 **학생 접속 주소**를 학생들에게 알려 준다. 제작용 5512번과 겹치지 않도록 교실 서버는 기본 5514번을 사용한다. 실행 창을 닫으면 공동 방도 종료된다.

터미널에서는 다음과 같다.

```powershell
node server/app.cjs 5514 --share
```

학생 기기를 교사 PC와 같은 네트워크에 연결하고 `http://교사PC의내부IP주소:5514/`로 들어간다. 교사는 시작 화면의 **같이 하기**에서 방을 만들고, 학생들은 같은 앱 주소에서 8자리 초대 코드를 입력한다. 최대 세 명이며 네 번째 참가자는 들어갈 수 없다. **균형 신전 함께하기**를 누르면 공유 상자·두 판·지레를 조작한다.

교실 공유 서버는 웹 게임과 `/api/coop/*`를 같은 주소에서 제공한다. 학생 기기에 별도 서버를 설치하거나 `127.0.0.1:5520`으로 접속하게 하지 않는다. Windows 방화벽이나 학교 네트워크의 기기 간 접속 제한은 해당 환경에서 확인해야 한다.

기존 `node tools/serve-local.cjs 5512` 명령도 같은 API를 포함한다. 이 명령은 교사 PC 내부에서만 접속하는 제작·검수용이며 `art/`·`reports/` 검수 페이지도 연다. 학생용 `server/app.cjs`는 런타임 파일만 제공하고 `.git`, 환경 파일, 서버 원본과 제작 자료는 제공하지 않는다.

## 동작과 보존

- 한 상자는 한 명만 소유한다. 두 학생이 같은 상자를 동시에 들면 서버가 충돌을 거부한다.
- 문은 서버가 실제 배치를 검사한 뒤 함께 연다. 클라이언트가 완료 표시를 보내 열 수 없다.
- 나간 학생의 상자 소유권은 해제된다. 공동 실험을 마치거나 중간에 나오면 시작한 범선/행성으로 복귀한다.
- 공동 실험 중 개인 자동 저장과 개인 신전 보상은 차단한다. 공동 대화도 개인 모험의 대화와 구분한다.
- 연결 실패는 설정 화면과 게임 알림에 표시한다. 개인 저장은 네트워크와 독립이다.

## 외부 호스팅

`server/app.cjs`는 Node HTTP 호스팅에서 정적 게임과 방 API를 함께 제공할 수 있다. 포트는 `PORT`, 바인드 주소는 `HOST`, 별도 허용 출처는 `COOP_ORIGINS` 환경변수로 지정한다. 정적 Vercel 사이트만 올린 상태에는 방 서버가 생기지 않는다.

정적 사이트와 방 서버를 나눠 운영할 때만 `index.html`의 `mumu-coop-endpoint` 메타 태그로 실제 HTTPS 방 서버 주소를 지정한다. 기본은 같은 주소의 `/api/coop`다. 세션은 서버 프로세스 메모리에 있으므로 여러 인스턴스로 무작정 분산하거나 재시작해도 방이 유지된다고 가정하지 않는다.

검사: `node tools/check-classroom-server.cjs`, `node tools/check-coop.cjs`, `node tools/check-coop-balance.cjs`, `node tools/check-coop-balance-http.cjs`. 서버 실행 후 `AUDIT_URL`을 지정해 `node tools/check-coop-room-browser.cjs`를 실행하면 세 개의 독립 브라우저가 같은 방을 조작하고 개인 저장을 보호하는지 확인한다.
