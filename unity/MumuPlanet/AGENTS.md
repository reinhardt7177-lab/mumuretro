# Unity 작업 지침

- 먼저 `Docs/AI/UnityProjectContext.md`와 상위 `unity/README.md`를 읽는다.
- Unity 6000.0.84f1 / URP / Input System을 기준으로 한다. 기존 웹 버전과 블렌더 원본을 삭제하거나 덮어쓰지 않는다.
- 구면 좌표 변환은 `Editor/BuildExploration.cs`의 한 경계에서 수행한다. 플레이어 크기 1.5, 행성 반지름 68을 지킨다.
- 생성 장면·메시·컨트롤러는 Unity 에디터 API로 만든다. `.meta`와 GUID를 보존한다.
- `Generated`는 재생성 가능한 자산이다. 수동 아트 작업은 복제한 장면이나 별도 자산에서 한다.
- 로직을 옮길 때는 해당 웹 버전의 실제 동작과 퍼즐 테스트를 함께 읽는다. 현재 장면에 없는 기능을 이식 완료로 보고하지 않는다.
- 이동 변경 후 Windows smoke 검사를 실행하고 결과 JSON·로그·화면을 확인한다. 컴파일 통과와 실제 게임 검증을 구분한다.
- 비용이 드는 서비스, 계정·클라우드 저장, 결제, 광고를 임의로 활성화하지 않는다. 현재 요구사항은 로컬 저장과 학생 2~3인 협동이다.
