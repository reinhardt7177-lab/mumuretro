# 물의 신전 v03 실제 화면 검토

## 수정 범위

v02 Blender 원본을 보존하면서 v03 네이티브 파일을 제작했다. 개별 기둥·아치 위에 채광구가 있는 궁륭을 잇고, 반복된 얼음 기둥을 연속 파쇄 빙벽으로 바꾸었다. 계단·회랑 마감, 물길 하부 옹벽, 물결 프리즈, 작은 마모와 균열을 추가했다.

실시간 표현은 석재의 강한 얼룩 대신 은은한 색상과 작은 노멀 굴곡을 사용하고, 푸른 빙하광과 따뜻한 반사광으로 나눴다. v03의 재질/메시 자산은 별도 폴더에 저장한다.

## 원본과 실행

- `art/glacier-water-temple/interior/v03/ice-hall-v03.blend`
- `art/glacier-water-temple/interior/v03/collection-hall-v03.blend`
- `art/glacier-water-temple/interior/v03/DESIGN.md`
- `unity/MumuPlanet/Builds/WaterTempleJourney/WaterTempleJourney.exe`

판정·물량·저장 형식 변경은 없다. 최종 실제 게임 캡처와 검사 결과는 아래에 기록한다. 자동 검사는 학생의 재미나 미술 완성도 검증과 구분한다. 레퍼런스와 같은 수준의 사실적 굴절/젖은 돌/베이크 조명을 달성했다고 주장하지 않는다.

## 검증 및 시각 검토

- v03 재빌드 종료 코드 0. 첫 빌드는 재질 처리 도중 정상 종료 기록 없이 중단되어, 작업 스레드를 줄이고 생성된 장면을 재빌드했다. 중단 원인은 확정하지 않았다.
- 실제 Windows 실행판에서 1구간 31개·2구간 39개 검사 통과. 총 70개.
- 실제 게임 이미지에서 천장/연속 빙벽/표면 질감을 확인했다. 띠 장식이 떠 보이는 부분은 Blender 석재 받침을 추가해 수정했으며, 최종 빌드/캡처로 확인한다.
- 새 아트만으로 사실적 레퍼런스와 동일한 결과라고 주장하지 않는다. 장식의 세부 충돌·조명 베이크·저사양 성능 및 실제 학생의 가독성/재미 평가는 남아 있다.

최종 받침 보정 빌드도 종료 코드 0. 같은 실행판의 1구간 31개·2구간 39개 재검사 통과. 최종 `ice/ice-ready.png`, `collection/collector-aligned.png`는 보정 후 실제 게임 캡처다.
