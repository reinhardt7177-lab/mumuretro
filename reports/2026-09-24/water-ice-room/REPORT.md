# 물의 신전 첫 방 — 얼음길

## 검증 결과

- Unity Windows 빌드 성공.
- 첫 방 실제 장면 기능 검사 31개 통과. 이동은 실행판의 `PlanetExplorer.Step`을 호출해 실제 충돌과 추락을 검사했다.
- 같은 변경된 플레이어 코드를 사용하는 행성 이동 검사 통과: `../water-ice-movement/result.json`.
- `ice-ready.png`, `room-complete.png`로 얼음길과 완료 상태를 확인했다.
- 발견한 누락 문자와 문 표지의 부모 크기 상속 문제는 장면 생성기에서 수정했다.

## 확인한 행동

5m 틈의 달리기 점프 우회 실패, 평지 걷기와 점프 착지, 팔찌 획득, 저수조 해빙과 도랑 채움, 부분 얼음의 지지 차단, 완성 얼음 위 실제 이동, 발밑 해빙 후 추락과 안전 복귀, 물 총량 유지, 반대편 착지 후 돌다리 고정, 녹은 도랑을 돌다리로 왕복, 기화수 회수와 펌프 재공급, 닫힌 수문 충돌, 가까운 수문 조작, 열린 문 통과 완료.

## 제한

독립 첫 방 기능 프로토타입이다. 주 게임 입구 연결·두 번째 방 이동·팔찌와 퍼즐 상태 영속 저장·최종 Blender 미술은 포함하지 않는다. 기존 기본 평면 이동은 유지하고 이 방만 실제 지지면 검사를 켰다. 하나의 도랑 전체를 한 지지 구간으로 다룬다.

자동 검사는 사람의 전체 키보드·마우스 조작 및 학생 재미 검사를 대체하지 않는다.
