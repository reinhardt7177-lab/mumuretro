# 물의 팔찌 시험실 검증

## 결과

- Unity 6000.0.84f1 Windows 독립 빌드 성공.
- 실행판 검증 27개 통과. `result.json` 참조.
- `trial.png` 생성 및 시각 확인. 검증 프로세스 정상 종료 확인.
- 최초 검증에서는 기능 검사 후 비동기 화면 저장/종료 중 충돌. 기존 프로젝트의 RenderTexture 기반 동기 캡처로 변경한 최종 검증은 정상 종료했다.

## 검증 범위

부분 냉각 취소와 재개, 한 번의 입력에서 한 상태 경계까지만 변화, 반복 가열/냉각의 질량 보존, 빈 대상 거부, 획득 거리, 손목 뼈 연결, 얼음 지지 충돌 켜기/끄기, 6m 사거리와 벽 가림, 상자 들기·수첩 사용 중 능력 차단, 차가운 집수판의 유지, 준비 전 회수조 이동, 준비 후 집수 수조 응결, 회수 펌프 반복 사용.

검사는 실행판에서 실제 장면과 기능 API를 호출했다. 모든 키·마우스 조작을 사람처럼 입력한 종합 플레이테스트, 학생 대상 재미 검사, 손목 전 동작의 시각 검사는 아니다.

## 변경 범위

- 신규 상태 규칙, 대상 표현, 시험실 능력 컴포넌트, 자동 검사.
- Unity Editor API를 통한 독립 장면 생성기.
- 기존 NavigatorPose에는 비활성 기본값의 왼팔 조준 자세만 추가.
- 기존 장면·플레이어 이동 방식·저장 형식·주 게임 빌드 목록은 변경하지 않았다.

## 남은 작업

실제 틈과 얼음 지지면을 사용하는 1실 이동/추락, 팔찌 및 물 상태 저장, 게임 내 신전 입구와 연결, Blender 최종 모델, 서리·수증기·물방울 연출, 손목 부착의 동작별 다듬기. 현재 상태는 독립 기능 프로토타입이다.
