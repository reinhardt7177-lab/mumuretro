# 정상 도착 · 태양 거울 발견 연출

## 구현
- 마지막 턱을 올라 정상에 착지하면 거울 발견 연출을 한 번 재생한다.
- 약 3.2초 동안 거울을 먼저 비춘 뒤 얼음 신전 방향으로 시선을 옮긴다.
- 이동, 마우스 오른쪽 버튼, Esc로 중단할 수 있다. E로 즉시 거울 조작에 들어갈 수 있다.
- 플레이어 이동을 강제로 비활성화하지 않는다. 수첩을 열거나 카메라 컴포넌트가 비활성화되면 연출을 정리한다.
- 같은 장면 방문 중에는 다시 올라와도 반복하지 않는다. 별도 발견 저장값은 추가하지 않았으므로, 게임 재실행 후 입구가 아직 얼어 있으면 다시 볼 수 있다. 이미 녹인 입구는 연출을 생략한다.

## 검증
- Unity Windows 빌드 성공: `unity/MumuPlanet/Logs/summit-discovery-v01.log`.
- 물의 돌산 실행 검사 128개 통과: `summit-discovery-v01/result.json`.
- 새 검사는 정상 도착 조건, 반복 방지, 거울 화면 구도, 시간 경과 종료, 이동 취소, 컴포넌트 중단, 거울 조작 전환을 포함한다.
- 기존 이동 실행 검사 통과: `summit-discovery-movement/result.json`.
- 실제 실행 캡처 `summit-discovery-v01/summit-discovery.png`에서 거울·캐릭터·신전과 한글 안내를 확인했다.

거울 모델과 신전 모델은 이번에 교체하지 않았다. 이번 범위는 정상 발견과 조작 연결 연출이다.
