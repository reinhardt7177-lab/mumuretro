# 등반 손발 접촉·올라서기 개선

## 적용 결과

- 손잡이를 기준으로 팔 각도만 바꾸던 방식에서, 실제 바위 접촉점에 손목을 맞추는 방식으로 변경했다.
- 손바닥과 발끝이 바위를 향하도록 회전한다. 발 디딤점은 캐릭터가 닿을 수 있는 주변 턱에서 고른다.
- 발이 닿지 않는 돌출 구간은 손으로 매달린 채 다리를 자유롭게 둔다. 다리 길이를 늘리지 않는다.
- 옆 이동은 손을 번갈아 옮기고, 도약 중에는 접촉 보정을 풀었다가 잡는 순간 다시 적용한다.
- 올라서기는 0.9초 동안 몸을 먼저 위로 끌어올린 뒤 선반 안쪽으로 이동한다. 완료·놓기·실패 시 접촉 자세를 해제한다.

## 검증

Windows 빌드 성공. [돌산 통합 검사](climb-contact-v03/result.json) **107개 통과**, [기존 탐사/이동 검사](climb-contact-exploration/result.json) 통과.

8개 정지 손잡이 지점에서 측정한 손목 목표 오차는 최대 약 **1.8cm**였다. 같은 자세를 반복 계산해도 손 위치가 누적해서 틀어지지 않는 것을 확인했다. 닿는 발의 접촉, 발을 뗀 돌출 구간, 잘못된 도약과 재시도, 정상 걷기 복귀, 거울/얼음/저장도 검사했다.

원본 캐릭터와 Blender 돌산은 그대로 유지했다. 현재 캐릭터 뼈대에는 개별 손가락 관절이 없어 손가락을 따로 오므리는 동작은 포함하지 않는다. 수치 검증은 손목·발목 목표점 기준이며, 모든 동작 프레임의 피부·바위 충돌을 보장하는 전신 물리 처리는 아니다.

실행판: `unity/MumuPlanet/Builds/Windows/MumuPlanet.exe`. 산 아래부터 확인하려면 기존 `-mumu-water-preview` 옵션을 사용한다. GitHub 업로드와 배포는 하지 않았다.
