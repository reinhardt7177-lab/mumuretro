# 순환의 성소 기능 검증

2026-09-24

## 결과

- Unity 6000.0.84f1 Windows 독립 빌드 성공.
- 실행판 기능 검사 35개 통과, 프로세스 정상 종료.
- `upper-prepared.png`, `cycle-complete.png` 생성 및 시각 검토.
- 팔찌의 바닥/벽 가림을 확장한 뒤 같은 실행판에서 첫 방 31개 검사 통과 (`../water-cycle-first-room`).
- 마지막 방 접근 검사 중 발견한 경사로 받침의 충돌과 회랑 바닥 겹침을 수정했다. 실제 이동으로 상층 높이 2.40m 도착 확인.

## 핵심 증거

- 초기 총량 6, 도랑 4, 남은 공급수 2.
- 냉각 후 건너기와 복귀 다리 고정.
- 아래에서 상층 수문 조작 불가, 고정 경사로로 올라가면 조작 가능.
- 차가운 집수판을 준비한 뒤 아래에서 혼자 기화 가능.
- 남은 2단위만 기화하면 성소가 덜 차고 출구는 닫힘.
- 물길 전환은 얼음을 가져가지 않음. 길을 녹여야 그 물을 이송할 수 있음.
- 수문 닫힘과 따뜻한 집수판 각각의 실패 후 물 회수·재시도 가능.
- 최종 성공까지 물 6단위 보존, 출구 개방 및 통과 완료.

## 검증의 한계

실제 장면과 이동/상호작용 API를 사용한 자동 검사다. 고정 경사로 이동은 직접 걸어서 검사했지만 반복 준비 구역 간 이동 일부는 위치 초기화를 사용했다. 사람이 키보드·마우스로 전체 과정을 진행한 재미/난이도 검사는 아직 아니다.

독립 퍼즐 시제품이며, 최종 Blender 미술·신 등장·보상·봉인·영속 저장·전체 신전 연결을 완료한 것이 아니다. 장치의 액체 이송 펌프와 영구 냉기를 저장하는 판은 명시적인 신전 장치 규칙이다.
