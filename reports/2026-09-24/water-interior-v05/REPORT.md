# 물의 신전 v05 — 재질과 반사

v04 Blender 형상을 유지하고 Unity에서 재질을 보강한다. 이전 생성 자산을 보존하기 위해 `Generated/WaterInteriorV05`로 분리한다.

- 석재: 월드 좌표 기반 입자·기공·낮은 색 변화. 위를 향하는 면에만 불규칙한 젖은 영역을 만들고 해당 부분의 명도와 거칠기를 낮춘다.
- 반사: 각 방에 128 해상도 반사 프로브 하나. 입장 후 한 번만 여러 프레임에 걸쳐 공간을 캡처한다. 움직이는 캐릭터나 장치가 실시간으로 갱신되는 거울은 아니다.
- 얼음길: 일정한 타일처럼 보이던 촘촘한 흰 선을 줄이고, 더 큰 불규칙 균열과 내부 색 변화로 바꾼다. 실제 투명 굴절은 아직 적용하지 않는다.
- 퍼즐 수치·이동·충돌·저장 형식은 변경하지 않는다.

## 검증

최종 빌드 종료 코드 0. 첫 구간 31개, 두 번째 구간 39개, 총 70개 자동 검사 통과. `ice/result.json`, `collection/result.json`과 실제 게임 캡처를 확인했다. 새 석재가 그림자에서 지나치게 어두워진 초안을 확인하여 보조 조명과 약한 간접광을 추가 반영했다. 최종 로그: `unity/MumuPlanet/Logs/water-interior-v05-final.log`.

저사양 PC 성능 측정과 사람의 전체 플레이 검증은 별도다. 반사 프로브의 갱신은 1회로 제한했지만 이 문서는 프레임률 개선을 입증하지 않는다. 실제 화면에는 여전히 석조 패턴의 반복과 단순한 빙벽 형상이 남아 있으며 레퍼런스 수준 완성으로 평가하지 않는다.
