# 풀 표시 켜기/끄기

풀의 성능 부담을 사용자가 직접 줄일 수 있도록 탐사 화면 오른쪽 위에 표시 버튼을 추가했다. G 키로도 전환할 수 있다.

- 최초 기본값: 풀 끔.
- 클릭하거나 G 키를 누르면 풀과 이삭을 함께 켜거나 끈다.
- 마지막 선택은 이 PC의 PlayerPrefs(`Mumu.Meadow.Visible`)에 저장하며 다음 실행·행성 재진입 때 읽는다.
- 끄면 모든 풀 MeshRenderer를 즉시 비활성화하고 거리별 표시 갱신도 중지한다. 지면·길·충돌·신전은 유지한다.
- 기존 초록/금색 UI와 한국어 글꼴을 사용한다.
- 메시 자산은 메모리에 남는다. 이번 기능은 렌더링 토글이며 메모리 스트리밍이나 자동 품질 조절은 아니다. FPS 개선 수치는 측정하지 않았다.

다음 콘텐츠 단계는 무게의 신전 두 번째 방이다. 상자를 양쪽 판에 2개씩 놓고 총무게를 같게 맞추면 문이 열리는 흐름으로 첫 방과 연결한다.

검증 명령: `./unity/check-meadow.ps1 -OutputDirectory ./reports/2026-09-21/unity-grass-toggle`

테스트는 사용자 설정을 저장해 두었다가 종료 시 원래대로 복원한다.

## 확인 결과

- Windows 빌드 성공.
- 실행판의 UI 레이캐스트 및 버튼 클릭 검사 통과.
- 풀을 끈 뒤 거리 갱신이 지나도 전체 풀 렌더러가 꺼져 있는 것을 확인했다.
- 켜기/끄기 저장 값과 저장 값 재적용 검사 통과.
- 켠 상태의 블렌더 잎·이삭 및 바람 렌더링 검사 통과.
- 꺼진 화면과 켜진 화면을 직접 확인했다. 한국어 버튼 글자와 상태 표시가 읽힌다.
