# 균형의 신 — 대화, 자동 귀환, 신전 밀봉

## 플레이 흐름

마지막 지렛대를 풀고 문 너머로 걸어가면 균형의 신을 만난다. 가까이 다가갈 때 카메라가 신을 비추고, 네 문장의 대화가 4.5초 간격으로 진행된다. E·Space·‘다음’ 버튼으로도 넘길 수 있다. 시작 직후의 중복 입력은 한 문장을 건너뛰지 못하도록 막는다.

대화는 세 퍼즐에서 배운 무게 비교·두 판의 균형·무게와 거리의 관계를 짚어 준다. 마지막 문장을 마치면 완료 기록을 저장하고 금빛 화면 전환과 함께 신전 밖으로 돌아온다. 신전에는 황금 봉인과 완료 표시가 나타나고 다시 들어갈 수 없다.

## 구현

- 기존 Blender v04의 `guardian` 조형물을 내보내 제단에 배치했다. 석조 알현 공간, 금빛 후광, 떠 있는 작은 축복 구슬을 더했다.
- 기존 신전의 색과 글꼴을 사용하는 uGUI 대화 패널을 추가했다. 대화 중 이동·카메라 조작·초기화·수동 복귀를 잠시 막는다.
- 마지막 방의 정답과 열린 문, 신과의 거리를 모두 확인한 뒤 이벤트가 시작된다. 멀리서 정답만 맞추거나 정답 없이 신에게 접근하면 시작되지 않는다.
- 완료 기록은 `Application.persistentDataPath/temple-completion-v1.json`에 보관한다. 현재는 **무게의 신전 완료 여부와 배운 내용만 저장**하며 중간 배치·위치·수첩 전체 저장은 아니다.
- 기존 파일 교체 시 `.bak`으로 이전 내용을 보관한다. 해석할 수 없거나 더 새로운 버전의 파일은 덮어쓰지 않고 해당 실행 동안만 완료 상태를 유지한다.
- 검사와 미리보기에는 `-mumu-progress-file <경로>`로 별도 기록을 사용해 실제 사용자 완료 기록과 분리한다.

## 재생성

1. Blender: `tools/blender/export_unity_balance.py -- --audience-only`
2. Unity: `Mumu.Editor.BuildTempleAudience.CreateAndBuild`
3. 검사: `unity/check-temple.ps1 -OutputDirectory <결과 폴더>`

전체 신전 생성에서도 알현 공간과 외부 봉인을 포함한다. 원본 웹 게임과 Blender 모델은 보존하며, 새 패키지·계정·온라인 서비스를 추가하지 않았다.

## 검증

- Windows 빌드 성공. 세 퍼즐 방부터 대화·자동 귀환·밀봉까지 **762개 검사 통과**.
- 별도 게임 프로세스로 재실행해 디스크의 완료 기록을 읽고, 봉인 표시·재입장 차단·닫힌 문의 충돌이 유지되는 것을 확인했다.
- 미완료 기록으로 정문 열기·입장·복귀·재입장 **56개 회귀 검사 통과**.
- 실제 실행 화면에서 알현 공간, 신과의 대화, 귀환 후 봉인을 확인했다. 대화 UI 한글 표시와 신의 정면 방향을 점검했다.
- 결과와 화면: [완료 흐름 증거](unity-temple-audience/), [미완료 문 검사](unity-audience-exterior-regression/). 빌드 로그: `tmp/unity-audience-build.log`.

## 범위

로컬 Windows용 무게의 신전 완료 흐름이다. 우주 범선 도입부, 수첩 UI, 중간 진행 저장, 다른 신전, WebGL와 협동의 이식 완료를 뜻하지 않는다.
