# 웹 Three.js 회귀 결정

## 결정과 적용 범위

2026-10-02 사용자 요청: “무무 메트로 유니티 버젼 폐기 웹 threejs 로 다시 회귀 할것임”.

현재 개발·실행·후속 구현 기준을 저장소 루트의 웹 Three.js 게임으로 변경했다. 기존 웹 소스는 남아 있어 과거 커밋으로 되돌릴 필요가 없다. 처음에는 Unity 프로젝트 보관으로 전환했다. 이후 사용자가 중요 자산 이전 뒤 Unity 버전 삭제를 명시적으로 요청했다. 최신 처리 결과는 [자산 이전 보고서](ASSET_TRANSFER.md)를 따른다. Blender 원본·기존 보고서와 다른 사용자 변경은 보존한다.

- 루트 `AGENTS.md`에 웹 작업 기준과 Unity 개발 종료를 명시했다.
- `SECOND_BRAIN.md`에 현재 상태·자료 위치·후속 구현 순서를 정리했다.
- 루트 README·CLAUDE와 Unity 문서에 현재 방향을 반영했다.
- 과거 CLAUDE의 길 안내 금지 문구를 사용자 승인 방향인 상단 퀘스트·선택형 황금 가루 안내로 수정했다.
- `.vercelignore`는 이미 `unity/`, `art/`, `reports/`, `tools/`를 배포에서 제외하고 있어 그대로 사용한다.

## 실행 기준

```powershell
node tools/serve-local.cjs 5512
```

주소: `http://127.0.0.1:5512/`. Three.js `0.160.0`은 `vendor/three/`에서 제공한다.

웹 저장은 `mumuplanet.progress.v1`과 `mumuplanet.progress.previous.v1`을 이어간다. Unity 저장 파일을 웹 저장으로 변환하는 기능은 없다. 이번 작업에서 실제 사용자 저장을 초기화하지 않았다.

## 후속 구현

핵심 모델 50개를 GLB로 변환하고 재사용 원본·참고 자료 272개를 해시 확인해 보존했다. 신전 외관·두 신 모델·수첩·상세 풀은 웹 게임에 연결했다. 전체 방 모델·돌산·태양 거울은 웹 모델 검수실에서 확인할 수 있으며 플레이 동선·기믹 연결은 후속 구현이다. 물의 팔찌와 세 상태 퍼즐은 웹의 기존 물 신전과 비교해 별도 이식한다. Unity 장면·C#·URP 재질이 웹에 자동 반영되는 것은 아니다.

이번 전환은 로컬 기준 변경이며 GitHub 업로드·Vercel 재배포는 수행하지 않았다.
