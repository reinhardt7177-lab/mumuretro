# 분리 사당 둘째 방 — 성질로 나누기

2026-09-08 · 로컬 적용 · 공개 사이트 미배포

**둘째 방을 자석과 투명 관찰 수조가 있는 작업장으로 개편했다.** 같은 모습의 시료 여섯 개를 검사하고, 바뀌는 세 기준에 맞춰 두 상자로 분류한다. [승인된 레퍼런스](SIFT_REFERENCE.md)의 두 번째 패널을 따랐다. 첫 방과 둘째 방까지 적용했으며, 다음은 ‘거름과 증발’이다.

![둘째 방 실제 화면](D:/mumumetro/reports/2026-09-08/evidence/sort-court/after-comparison.png)

## 적용 내용

| 요소 | 실제 동작과 표현 |
|---|---|
| 작업장 | 12×12u 방과 기존 출입문 위치를 유지했다. 사암 바닥·기둥, 목재 받침과 황동 테두리를 적용했다. |
| 시료 여섯 개 | 왼쪽 받침에 배치했다. 모두 같은 0.62u 상자 형상과 같은 재질을 공유한다. 재료 이름이나 정답 색은 표시하지 않는다. |
| 자석 | 가까이 다가가면 자성을 가진 시료만 흔들린다. 자석 반응과 부력은 서로 다른 성질로 유지했다. |
| 관찰 수조 | 불투명 원통을 투명한 사각 수조로 바꿨다. 수면 기준선과 시료가 옆에서도 보인다. 물속에서도 원래 시료와 크기·재질이 같다. |
| 분류 상자 | 속이 보이는 낮은 목재 상자 두 개와 기준 표지를 배치했다. 기준이 바뀌면 표지와 시료 배치가 갱신된다. |
| 재시도 | 잘못 담은 시료를 E로 꺼낼 수 있다. 다른 시료가 수조에 있거나 놓을 장치가 없으면, 든 시료를 E로 원래 받침에 반환한다. |
| 모바일 | 물속 시료의 꺼내기 안내가 `E —`로 시작하도록 수정해 터치 E 버튼과 연결했다. 수첩을 읽는 동안 관찰 시간과 힌트 시간이 멈춘다. |
| 입구 시야 | 화면 중앙을 가리던 출입문의 낮은 장식 가로대를 상인방 아래로 옮겼다. 문틀을 카메라 충돌 대상으로 등록했다. |

첫 두 기준은 ‘자석에 붙는가’와 ‘물에 뜨는가’의 순서가 섞이고, 세 번째는 ‘붙으면서 가라앉는가’다. **자석에는 붙지만 물에는 뜨는 속 빈 쇠통**을 그대로 유지했다. 모든 쇠가 가라앉는다는 식으로 문제를 단순화하지 않았다.

## 수조와 저장

수면 높이는 1.34u, 뜬 시료의 중심은 약 1.39u, 가라앉은 시료의 중심은 0.59u다. 시료의 반높이는 0.31u이므로 가라앉은 시료는 수면 아래에 완전히 들어간다. 약 0.625초에 걸쳐 결과 위치로 이동한다. 관찰 중에는 결과를 먼저 선언하지 않고 움직임을 보도록 안내한다.

![물 위에 뜬 시료](D:/mumumetro/reports/2026-09-08/evidence/sort-court/water-floating.png)

![물속으로 가라앉은 시료](D:/mumumetro/reports/2026-09-08/evidence/sort-court/water-sinking.png)

개편 전에 물속 검사 40% 진행 상태와, 그 상태에서 다른 시료를 들고 있는 기록을 각각 보관했다. 새 저장은 기준 순서·라운드·손과 수조의 소유권·검사 시간·각 상자의 시료 목록을 기록한다. 옛 기록을 읽을 때 장면 노드를 되살리지 않고 새 모델에 상태를 옮긴다. 기존 둘째 방 안의 재개 좌표는 받침과 겹치지 않도록 입구로 옮기며, 들고 있는 시료·관찰·힌트·문 진행은 유지한다.

저장 복원 자체는 분류를 진행하지 않는다. 자석에 반응하는 미세 흔들림의 위상은 새로 시작하며, 물속 검사 시간은 그대로 이어진다.

| 소스 | 100개 모듈, 260개 로컬 import, 19개 vendor 해시, 음악 경로 통과 |

검사는 외부 요청을 막은 독립 Edge 브라우저에서 수행했다. 실제 이동 입력과 E/터치 입력을 사용했지만 자동 검사 도구는 시료의 정답을 알고 조향한다. 이 결과가 처음 하는 사람의 이해도나 재미를 입증하는 것은 아니다.

같은 씨드와 입구 시점의 전체 렌더 호출은 **642 → 607**, 삼각형은 **16,877 → 18,471**이었다. 장치 디테일로 삼각형은 늘었지만 반복 구조를 묶어 렌더 호출을 줄였다. 프레임 속도나 실기기 성능 측정값은 아니다. 비교 캡처에서 장식 가로대의 위치가 달라진 것은 시야 수정의 결과다.

## 검증 중 바로잡은 판단과 남은 개선

- 첫 배치는 마지막 시료 앞의 접근점이 분류 상자 충돌 범위 안에 있었다. 순간이동 검사는 놓쳤지만 실제 보행에서 막혔다. 받침 간격을 조정하고 전체 경로를 다시 통과했다.
- 모바일 수첩을 닫은 직후 버튼이 안 보이는 것을 추가 앱 오류로 의심했다. 확인 결과, 검사 도구가 닫기 입력이 새 행동으로 이어지는 것을 막는 한 프레임에서 멈췄다. 정상 다음 프레임까지 검사하도록 수정했다. 기존 꺼내기 안내의 E 버튼 연결 문제와는 별개다.
- 레퍼런스의 투명 수조·열린 상자·목재와 사암 배치는 반영했지만, 실제 화면은 낮은 다각형 수와 강한 황토색 조명으로 더 단순하다. 목재 결, 석재 마모, 식물과 천막, 물결·굴절·부드러운 접촉 그림자는 후속 미술 개선이 필요하다.
- 수조는 정해진 부력 성질을 보여 주는 교육용 모형이다. 실제 재질 밀도·유체·자기장 시뮬레이션은 아니다. 물은 투명 수면으로 표현하며 수중 굴절은 없다.
- 좁은 휴대전화 화면에서는 가까운 수조와 표지가 한 시야에 다 담기지 않을 수 있다. 회전 시점과 하단 조작 안내로 플레이할 수 있으며, 모바일 구도는 더 다듬을 여지가 있다.
- 관찰 내용을 사용자가 기억해야 하는 기존 규칙은 유지했다. 수첩에 직접 비교 기록을 남기는 기능은 이번 범위에 포함하지 않았다.

다음 작업은 **셋째 방 ‘거름과 증발’**이다. 거름종이에 남는 모래와 가열 접시에 남는 소금을 구분해 보여 주고, 그 뒤 마지막 신전에서 분리 방법의 조합을 다룬다.
