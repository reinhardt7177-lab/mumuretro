# 분리 사당 첫 방 — 체 고르기 구현 보고서

2026-09-08 · 로컬 적용 · 공개 사이트 미배포

**분리 사당의 첫 방 ‘체 고르기’를 작업장으로 개편했다.** [분리 사당 레퍼런스](SIFT_REFERENCE.md)의 체·작업대·경사받이·받침 접시를 적용하고, 세 주문과 두 단계 재체질, 이전 저장 복원을 유지했다. 나머지 두 관문과 마지막 분리 신전의 그래픽 개편은 다음 단계다.

![개편한 체 고르기 작업장](D:/mumumetro/reports/2026-09-08/evidence/sieve-court/after-comparison.png)

## 달라진 플레이와 공간

| 요소 | 적용 내용 |
|---|---|
| 공간 | 기존 12×12u 동선을 유지하면서 사암 기둥·밝은 바닥·목재 작업대를 배치했다. |
| 체 선반 | 체를 옆으로 옮겨 접시 앞 동선을 비웠다. 선반에서는 비스듬히 세워 구멍 간격을 보여 주고, 들거나 끼우면 수평으로 놓인다. |
| 작업대 | 체를 끼우는 높이를 1.2u로 낮췄다. 불투명한 상판 대신 열린 틀과 테두리를 사용한다. |
| 체질 결과 | 큰 알갱이는 위에 남고 작은 알갱이는 아래 접시에 보인다. 경사받이로 두 공간을 연결했다. |
| 주문 | 크기가 다른 알갱이 표지와 세 진행 점을 표시한다. 굵은 것만·굵은 것과 중간·중간만 남기는 세 주문을 유지한다. |
| 재체질 | 아래 접시 앞에서 E를 누르면 빠진 재료만 다시 사용한다. 중간 알갱이만 남기려면 이 과정을 거쳐야 한다. |
| 되돌려 놓기 | 빈 틀 앞이 아니거나 이미 체가 끼워져 있으면 E로 들고 있는 체를 선반에 돌려놓는다. 교체 도중 손이 막히는 상황을 없앴다. |
| 충돌 | 작업대·선반·받침 접시에 충돌을 추가했다. 작업대 옆과 접시 앞의 서로 다른 자리에서 조작한다. |

원래 세 주문 중 두 주문은 한 번의 체질로, 중간만 남기는 주문은 두 번의 체질로 해결한다. 첫 번째 결과를 버리지 않고 다시 사용하는 흐름을 줄이지 않았다.

## 구멍과 알갱이 크기

기존 모델은 알갱이의 모양과 체의 살 개수를 따로 정했다. 새 모델은 게임의 mm 값을 **같은 축척으로 확대한 모형**으로 만든다. 실제 실험 도구의 절대 크기를 재현했다는 뜻은 아니다.

| 종류 | 판정에 쓰는 크기 | 표시 모델의 크기 |
|---|---:|---:|
| 큰 구멍 | 8mm | 0.72u |
| 중간 구멍 | 4mm | 0.36u |
| 작은 구멍 | 1mm | 0.09u |
| 굵은 알갱이 | 6mm | 0.54u |
| 중간 알갱이 | 3mm | 0.27u |
| 고운 알갱이 | 0.6mm | 0.054u |

체의 살 사이에는 실제 빈 공간이 있다. 반복 메시의 행렬에서 살 사이 간격을 측정하고, 광선으로 빈 구멍과 막힌 살을 구분했다. 알갱이 메시의 경계 크기도 직접 측정해 세 체와 세 종류 알갱이의 **아홉 가지 분리 판단**이 일치하는지 확인했다.

알갱이는 모서리가 깎인 형태이며, 종류마다 아홉 개씩 표시한다. 개별 입자의 회전·충돌을 시뮬레이션하지 않고 지정된 크기 기준으로 종류를 나누는 교육용 모형이다. 결과는 위·아래 접시로 즉시 재배치된다. 시안의 떨어지는 입자 흐름을 실시간 체질 애니메이션으로 구현한 것은 아니다.

## 저장과 함께 고친 문제

개편 전에 실제 브라우저에서 두 기록을 보관했다. 하나는 체가 끼워져 위·아래 재료가 나뉜 상태, 다른 하나는 아래 재료를 올린 뒤 작은 체를 들고 있는 상태다.

새 버전은 메시 번호 대신 주문 순서·라운드·들고 있는 체·끼운 체·현재 재료 종류를 기록한다. 기존 기록도 검증한 뒤 이관한다. 체 선반과 충돌이 달라졌으므로 옛 기록의 재개 위치가 첫 방 안이면 입구 안전 지점으로 옮긴다. 재료·주문·힌트와 들고 있는 체는 유지한다. 복원 자체가 다음 주문을 해결하지 않도록 표시만 재구성한다.

저장 검증 도중 성질 분류 장치의 자석이 재접속을 반복하면 방향이 달라지는 기존 오류를 발견했다. 저장된 회전을 복원한 뒤 세 축 중 한 축만 덮어쓰는 과정에서 생긴 문제였다. 손을 따라오는 자석은 매번 세 축을 같은 기준으로 설정하도록 고쳤다. 성질 분류의 문제나 분류 판정은 바꾸지 않았다.

작업대에 체가 이미 있는데 다른 체를 들면, 기존 조작으로는 끼우지도 내려놓지도 못했다. 들고 있는 체를 선반으로 돌려놓는 조작을 추가하고, 작업대가 찬 경우와 작업대에서 떨어진 경우를 각각 검사했다.

## 실제 실행 검증

| 검사 | 결과 |
|---|---|
| 첫 방 전용 | 15개 통과 |
| 구멍·알갱이 | 실제 메시 간격과 경계 크기로 아홉 판단 일치. 구멍과 살의 광선 통과 여부 확인 |
| 중간 표시 | 비어 있지 않은 재료 조합 7개 × 체 3개, 21상태에서 위·아래 소속과 표시 여부 일치 |
| 보행 | 사당 입구에서 실제 입력으로 체를 집고 끼우고, 아래 접시를 재사용해 세 주문을 완료한 뒤 다음 통로까지 이동 |
| 충돌·카메라 | 작업대와 접시 내부 진입 차단. 보행 가능한 위치의 카메라 144시점에서 작업장 구조물 회피 |
| 저장 | 옛 끼운 상태·들고 있는 상태 이관, 새 저장 재접속, 복원된 체를 걸어가서 사용, 중복 소유의 원자적 거부 |
| 오류 주입 | 별도 브라우저에서 체 구멍만 절반으로 줄였을 때 표시 크기와 분리 판정의 모순 검출 |
| 모바일 | 터치 E로 두 단계 주문을 한 번만 완료. 수첩을 열면 들고 있는 체와 힌트 시간이 정지 |
| 사당 저장 회귀 | 42개 통과. 내장 A~W 23그룹 실제 실행과 사당 상태·저장소 보존 포함 |
| 소스 | 97개 모듈, 254개 로컬 import, 19개 vendor 해시와 음악 경로 확인 |

보행은 실제 이동 입력을 사용하지만 검사 도구가 정답을 알고 조향한다. 전체 게임의 사용자 플레이 테스트나 학습 효과 검증을 뜻하지 않는다. 모바일은 Edge의 390×844 터치 에뮬레이션이며 실제 휴대전화 성능은 측정하지 않았다.

![모바일에서 두 단계 주문을 마친 상태](D:/mumumetro/reports/2026-09-08/evidence/sieve-court/after-mobile.png)

기존 저장 회귀 도구는 물건과 작업대의 중심까지 걸어가도록 작성돼 있었다. 새 충돌 때문에 중심으로 들어가지 못하는 것은 정상이다. 검사 목적을 유지하면서 선반 앞과 작업대 옆의 실제 조작 위치로 경로를 바꿨다. 충돌을 제거해서 검사를 통과시키지 않았다.

## 레퍼런스 비교와 남은 표현 차이

같은 씨앗·체질 상태·입구 위치·카메라 각도·1440×900 해상도로 전후 화면을 남겼다. 아래는 수정 전 화면이다.

![개편 전 체 고르기](D:/mumumetro/reports/2026-09-08/evidence/sieve-court/before.png)

시안의 원형 체, 두 결과, 접근 가능한 접시, 사암과 목재 구분을 구현했다. 초기 화면에서는 작업대가 높고 네모 알갱이가 덩어리처럼 붙어 보였다. 작업대를 낮추고 같은 경계 크기의 각진 다면체로 알갱이를 바꿨다. 모바일 캡처에는 입력 후 화면을 다시 그려 최신 상태를 기록했다.

현재 게임은 시안보다 표면 질감과 원경이 단순하고 황토색 조명이 강하다. 작은 모래는 입구의 먼 시점에서 잘 보이지 않으므로 가까이 관찰해야 한다. 모바일 세로 화면에서는 작업대와 선반을 함께 보려면 시점을 돌려야 한다. 검은 안내판을 석재 표지에 자연스럽게 통합하는 작업, 떨어지는 입자 연출과 원경 밀도는 추가 개선 여지가 있다.

렌더 비용은 같은 비교 장면에서 후처리를 포함한 전체 패스를 합산했다. 그리기 호출은 **782회 → 669회**, 삼각형은 **14,103개 → 20,863개**였다. 반복 메시로 체의 살과 건축 부품을 묶어 호출은 줄었지만, 원형 테두리와 알갱이 표현으로 삼각형은 늘었다. [수정 전 측정](evidence/sieve-court/before.json)과 [수정 후 측정](evidence/sieve-court/report.json)의 `metrics`에 보관했으며, 이 수치만으로 실제 기기의 프레임 속도 향상을 주장하지 않는다.
