## 1. 앱의 정체성과 개선 방향

무무 행성은 연구실의 소포에서 출발해 작은 구형 행성을 탐험하고, 초등 과학의 여섯 주제를 조작하며 수첩을 채우는 1인용 3D 웹 게임이다. 사당 6곳에 일반 관문 17개와 마지막 퍼즐 6개가 있으며, 채집·덫·요리·귀환·엔딩이 탐사 흐름에 연결된다.

이번 개선은 기존 이야기와 퍼즐을 유지하면서 플레이어가 중단하고 돌아올 수 있고, 설명을 믿고 행동할 수 있으며, PC와 작은 화면에서 같은 기능을 쓸 수 있도록 정리한다.

### 함께 다듬은 경험

- PC에서도 수첩 획득 후 오른쪽 위 📓 버튼을 표시하고, N 키와 키보드 버튼 조작을 지원한다. 수첩 안에서 닫고 돌아올 수 있는 경로도 정리한다.
- 물의 온도 손잡이에 `온도 단계 바꾸기 (110°C → -10°C)`처럼 다음 설정값을 표시한다. 순환의 끝에서 냉각되는데도 올리기라고 부르던 모순을 없앴다.
- 용암 수로의 경고 중 프롬프트를 `E — … · ⚠ 장치 경고` 순서로 바꿨다. 실제로 조작할 수 있는 동안 터치 E 버튼이 사라지지 않도록 했다.
- 물의 세 상태를 얼음·물·수증기로 정리하고, 보이는 하얀 김과 기체인 수증기를 구분했다.
- 버섯 규칙은 채집 전 힌트와 채집 후 기록 모두에서 가상 행성에 한정했다. 향풀·암염 문구도 관찰한 대상의 범위를 드러내도록 바꿨다.
- 동적으로 넣는 명사의 조사를 공통 함수로 처리해 `얼음로`를 `얼음으로`로 바로잡았다.

게임 속 문구는 기존 화자를 유지한다. 주인공의 기록은 혼잣말, 지킴이의 목표와 안내는 해라체를 사용한다.

## 3. 저장의 범위와 한계

자동 저장은 같은 사이트 주소의 같은 브라우저 저장소를 사용한다. 계정 로그인이나 서버 동기화는 없다. 이번 구현의 저장 시점은 **2초 간격, 주요 행동, 장면 이동, 페이지 종료**다. 시작 화면에서 저장 시점과 얻은 구슬 수를 보고 이어서 탐사하거나 새 탐사를 고를 수 있도록 한다.

| 포함하는 기록 | 복구 범위 |
|---|---|
| 연구실 | 소포·수첩·다이얼·귀환·엔딩 관련 진행 |
| 사당 | 얻은 구슬과 완료한 사당 |
| 들 | 채집 발견, 재료 수량, 덫과 미끼 관련 상태 |
| 부엌 | 요리 기록과 저장 대상으로 정한 부엌 상태 |
| 수첩 | 면·읽은 기록·새 기록 표시 관련 상태 |
| 지도·행성 | 탐험한 구역과 행성 위의 위치·방향 |

**미완료 사당의 상자·손잡이·퍼즐 진행을 그대로 되살리는 중간 저장은 아니다.** 사당 안에서 닫으면 해당 사당의 입구 밖에서 이어간다. 완료한 구슬과 탐사 기록은 복구 대상으로 유지한다.

새 탐사에서는 이전 기록 한 개를 백업한다. 백업에 실패하면 이전 원문을 보존하고 이번 탐사는 저장 없이 시작하며 화면에 알린다. 여러 슬롯을 선택하거나 백업을 화면에서 복원하는 기능을 제공한다는 뜻은 아니다. 브라우저의 사이트 데이터를 지우거나 주소·브라우저·기기를 바꾸면 같은 기록을 불러올 수 없다. 저장 차단·손상·부분 복원·백업 실패 조건도 브라우저에서 확인했다. 엔딩 대사 도중 닫으면 아직 마치지 않은 대사 묶음부터 다시 읽을 수 있다.

통합 작업 중 대사 정지 직후 첫 화면 카메라가 이전 장면에 남는 문제와 엔딩 카드의 전환 타이머 충돌을 찾아 수정했다. 장면 전환 때 카메라를 먼저 배치하고, 엔딩을 열었으면 이전 숨김 타이머가 화면을 내리지 않도록 했다. 일부 통합 재실행에서 부팅 대기 시간 초과가 발생했으나 마지막 전체 실행과 별도 엔딩 8회 부팅에서는 재현되지 않았다.

추가로 3단계 힌트가 90초 직후 곧바로 덮이던 문제를 수정해 45·90·135초에 차례로 열리도록 했다.

공개 사이트에는 배포하지 않았다. 이번 결과는 로컬 작업본의 수정·검증 결과다.

## 5. 설계 검토와 남은 과제

Nintendo의 공식 『젤다의 전설 티어스 오브 더 킹덤』 안내는 주변 환경을 관찰하고 얻은 능력을 사용해 사당을 푸는 흐름을 설명한다. 이를 비교 기준으로 삼으면, 이번 물·시간 신전 수정은 플레이어가 이미 배운 온도 조절과 기록의 표지를 사용하도록 안내를 맞춘 것이다. 이는 설계상의 비교이며 같은 수준의 완성도나 학습 효과가 입증됐다는 뜻은 아니다. [Nintendo 공식 사당·능력 안내](https://play.nintendo.com/news-tips/tips-tricks/tears-of-the-kingdom-tips-tricks/)

남은 개선과 검증은 다음과 같다.

1. **실제 학습자와 관찰한다.** 첫 소포·다이얼·사당 발견에서 걸리는 시간, 조작 실패와 개념 오해를 구분해 기록한다. 사당 완료만으로 개념 이해를 판정하지 않는다.
2. **과학 모형의 조건을 더 정리한다.** 온도와 상태의 표현은 단순화된 게임 규칙이다. 교육과정 버전·성취기준·각 퍼즐·확인 질문을 대응시키는 별도 검토가 필요하다.
3. **색을 보완하는 단서를 늘린다.** 물의 상태 표지는 멀리서도 모양이나 글자로 구분할 수 있는지 개선할 여지가 있다. 현재 이름 안내는 제공되지만 3D 표지의 색 의존성은 남아 있다.
4. **실제 기기와 긴 탐험을 검사한다.** 학교 태블릿·Safari·인앱 브라우저, 장시간 프레임 속도·발열, 일반 조작만으로의 완주를 확인한다.
5. **저장 복구 경험을 확장할지 결정한다.** 백업 복원 화면·기기간 이동·사당 중간 저장은 현재 범위 밖이다. 필요성이 확인되면 기존 저장 형식의 호환을 유지하며 추가한다.

이번 수정은 기존 구조를 전면 교체하지 않고 사용자에게 직접 영향을 주던 실패를 줄이는 작업이다. 아직 확인하지 않은 학습 향상률·전체 플레이 시간·모든 기기의 성능을 홍보 수치로 사용하지 않는다.

## 6. 교육 정확성의 근거

- **전진은 항상 존재하는 예고가 아니다.** USGS는 모든 본진에 전진이 있는 것은 아니며, 어떤 작은 지진이 전진인지는 같은 곳에서 더 큰 지진이 난 뒤에야 구분할 수 있다고 설명한다. 게임의 경고를 장치에 한정한 근거다. [USGS 전진·본진·여진](https://www.usgs.gov/media/videos/foreshocks-mainshocks-and-aftershocks), [USGS 전진과 여진의 구분](https://www.usgs.gov/faqs/foreshocks-aftershocks-whats-difference?items_per_page=6&os=v0&page=1)
- **수증기와 보이는 물방울을 구분한다.** 미국 국립기상청 자료는 눈에 보이지 않는 수증기가 응결하면 보이는 물방울이나 얼음 결정이 된다고 설명한다. 김을 물의 기체 상태와 같게 적던 문구를 고친 근거다. [NOAA/NWS 구름 생성 자료](https://www.weather.gov/source/zhu/ZHU_Training_Page/clouds/cloud_development/clouds.htm)
- **채집 규칙의 적용 범위를 드러낸다.** 고리와 갓의 모양으로 정답을 고르는 기준은 이 게임의 가상 생물 데이터다. 실제 식용 버섯 판별법을 조사·검증한 내용으로 제공하지 않는다. [게임 채집 규칙](../../src/data/forage.js)

과학 문구 수정과 퍼즐 기능 검사는 완료한 범위이며, 교사 검토·학생 사용성·교육과정 전체 대응 검증은 별도의 과제로 남는다.
