# 물의 신전 2구간 안내 개선

## 변경

- 집수판 냉각, 위층 손잡이 정렬, 아래 용기 가열, 증기 응결, 회수, 출구 단계를 실제 물과 장치 상태에서 계산한다.
- 목표 3칸 대비 집수 비율과 회수조의 물 양을 표시한다. 정렬 성공 여부는 색상과 문장으로 함께 설명한다.
- 냉각한 집수판의 낙하 예상선을 손잡이를 놓은 뒤에도 유지한다. 수첩과 다리 완성 후에는 숨긴다.
- 다리가 올라오는 중과 실제 건널 수 있는 상태를 구분한다.
- 자동 검사 캡처와 실제 게임이 같은 HUD 갱신 함수를 사용한다.
- 첫 실제 캡처에서 URP Unlit 재질이 선의 버텍스 색을 표시하지 않는 문제를 발견했다. 재사용 MaterialPropertyBlock으로 재질의 기본색을 설정하고 선 폭을 0.045m로 조정했다.

## 범위

물의 양, 냉각·가열 속도, 정렬 허용 범위, 다리 해제 조건과 저장 형식은 유지한다. 새 블렌더 모델이나 증기 입자 효과를 추가한 작업은 아니다. 안내의 실제 난이도는 학생 플레이로 별도 확인해야 한다.

## 검증

- 전체 장면·글꼴 생성 빌드 및 색상 수정 후 최종 Windows 빌드 성공(종료 코드 0).
- 최종 실행판: 집수실 46개, 다섯 프로세스의 여정·저장 복원 32개, 총 78개 검사 통과.
- `collection/guide-misaligned.png`와 `collection/collector-aligned.png`를 직접 확인해 황금색/청록색 낙하선과 한글 안내가 일치함을 확인했다.
- `collection/guide-collecting.png`에서 부분 집수 비율과 3칸 목표 표시를 확인했다. 결과 JSON과 플레이어 로그는 `collection`, `journey-final`에 보관한다.
- 자동 검사는 실제 학생 대상 사용성 평가나 성능 측정을 대신하지 않는다.
