# 물의 신전 3구간 순환 안내

## 변경

- 총 6칸의 물 중 얼음길에 4칸을 쓰고 성소에는 5칸이 필요하다는 관계를 HUD에 표시한다.
- 성소의 물, 도랑에 남은 물, 회수조의 물을 실제 상태에서 읽어 보여 준다.
- 냉각·건너기·돌다리 대기·상층 수문·집수판 냉각·물길 전환·가열·얼음길 재사용·회수·출구를 현재 장치와 물의 상태에 맞춰 안내한다.
- 남은 2칸만 성소에 넣었을 때 얼음길의 물을 다시 쓰도록 설명한다. 안전한 복귀 돌다리가 준비되기 전에는 얼음을 녹이라고 안내하지 않는다.
- 닫힌 수문이나 따뜻한 집수판으로 실패하면 해당 원인을 안내한다. 회수조 양으로 물이 보존됨을 확인할 수 있다.
- 문이 움직이는 중과 실제 통과 가능한 상태를 구분한다. 캡처와 실게임은 동일한 HUD 갱신 함수를 사용한다.

## 범위와 한계

퍼즐 조건, 물의 양, 이동·충돌, 저장 형식과 기존 에셋은 유지했다. 이번 작업은 3구간의 상태별 안내 개선이며 새 신전 모델이나 시각 효과 제작은 아니다. 단계별 안내가 추리 난이도에 주는 영향은 학생 플레이로 확인해야 한다.

## 검증 결과

- Unity Windows 전체 빌드 성공(종료 코드 0).
- 마지막 구간 41개, 다섯 프로세스의 여정·저장 복원 32개, 총 73개 검사 통과.
- 실제 게임 캡처 `cycle/guide-reuse-ice.png`, `cycle/guide-closed-valve.png`에서 한글과 3줄 패널의 표시, 성소 2칸/목표 5칸, 도랑 4칸 또는 회수조 4칸이 안내와 일치함을 확인했다.
- 3구간의 건축은 아직 기본 도형 중심의 프로토타입이다. 1·2구간 수준의 Blender 아트 적용은 후속 작업이다.
