# 순환의 성소 그래픽 v08

## 제작 및 연결

- 보존된 v07 Blender 신전을 바탕으로 3구간 전용 `cycle-hall-v08.blend`를 제작했다.
- 석주·아치·빙하 벽에 상층 회랑의 석판/난간/기둥, 경사로 마감, 청동 가열 용기와 배관, 수조 장식, 밸브 손잡이를 추가했다.
- 정적 건축 132,928 삼각형. 문·복귀 다리·집수판 장식은 기존 별도 에셋을 재사용한다.
- Unity의 원본 3구간 장면과 연결 여정 장면에 적용했다. 기존 충돌체와 퍼즐 동작 시간은 유지한다.
- 최초 검사용 카메라는 실외에 있어 추가된 빙하 벽에 가렸다. 실제 내부를 확인할 수 있도록 검사 카메라를 실내로 옮겼다.

## 한계

기존 레퍼런스를 참고한 첫 3구간 아트 적용이다. 레퍼런스 수준의 완성도나 성능 향상을 달성했다고 평가하지 않는다. 원본과 생성 스크립트는 수정 가능하게 보관했다.

## 검증 결과

- Unity 전체 빌드 및 캡처 수정 빌드 성공(종료 코드 0).
- 새 건축 적용 후 마지막 구간 41개, 여정·저장 복원 32개 검사 통과. 캡처 카메라만 수정한 최종 실행판에서도 마지막 구간 41개 재통과.
- `cycle/guide-reuse-ice.png`를 직접 확인했다. 실내 아치·빙하 벽, 성소 수조, 장식문, 회랑과 난간, 청동 배관이 게임에서 렌더링된다.
- 현재 캡처에서는 전경 배관이 중앙 시야 일부를 차지한다. 실제 카메라 회전 시 가림 정도와 회랑·경사로의 추가 장식은 후속 플레이 검토 대상이다.
