# 첫 얼음길 구간 안내 정리

## 변경

- 팔찌 획득 → 저수조 해빙 → 도랑 채우기 → 냉각 → 건너기 → 수문 열기 단계를 실제 상태에서 계산한다.
- 얼음이 부족하면 냉각 비율을 표시한다. 실제 발판이 활성화되기 전에는 건너기 목표를 표시하지 않는다.
- 증기가 회수되면 저수조 대신 회수 펌프를 안내한다. 이미 건넌 뒤에는 문 열기 목표를 유지한다.
- 지금 확인할 장치 또는 착지점에 작은 황금 원을 표시한다. 막힌 길을 가로지르는 경로선은 만들지 않는다. 수첩을 열거나 문이 올라갈 때는 숨긴다.
- 팔찌 획득 전에는 아직 쓸 수 없는 팔찌 모드 조작을 감춘다. 선택한 장치가 사거리 밖이거나 플레이어와 장치 사이가 막히면 이유를 표시한다.
- 실제 HUD 갱신 함수를 캡처 검사에서도 사용해 시험 화면과 실제 안내가 달라지는 문제를 줄였다.
- 이전 상태를 복원할 때 다리와 수문의 표시·충돌도 함께 되돌린다. 기존 저장 형식은 유지한다.

## 검증 결과

- Unity Windows 빌드 성공(종료 코드 0).
- 첫 구간 자동 검사 45개와 다섯 프로세스의 여정·저장 복원 검사 32개, 총 77개 통과.
- 실제 게임 캡처에서 진입 안내, 냉각 진행률, 회수 안내의 한글과 패널 내 배치를 확인했다.
- 황금 원은 제단·도랑·회수 장치의 현재 목표 위치에 표시된다. 회수 캡처에서는 장치가 화면 왼쪽 가장자리에 있어 원 일부만 보인다. 화면 밖 방향 표시는 이번 변경에 포함하지 않았다.
- 캡처: `ice/guide-entry.png`, `ice/crossing-half-frozen.png`, `ice/guide-recovery.png`.

## 확인할 점

자동 상태 검사와 게임 캡처는 실제 학생의 이해도를 대신하지 않는다. 다음 사용자 플레이에서는 냉각 완료 전 진입 여부와 펌프 복귀 안내를 이해하는지를 관찰해야 한다.
