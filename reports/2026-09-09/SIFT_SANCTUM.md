# 마지막 분리 신전 — 네 혼합물과 도구의 조합

2026-09-09 · 로컬 적용 · 공개 사이트 미배포

**분리 사당의 마지막 신전까지 작업장 미술 기준으로 개편했다.** [승인된 레퍼런스](../2026-09-08/SIFT_REFERENCE.md)의 네 번째 패널을 기준으로 도구 네 개, 혼합물 네 그릇, 체를 든 지킴이를 만들었다. 분리 사당은 세 관문과 마지막 신전 모두 첫 개편을 마쳤다.

![개편한 마지막 분리 신전](D:/mumumetro/reports/2026-09-09/evidence/sift-sanctum/after-comparison.png)

## 적용한 공간과 문제

| 요소 | 실제 적용 |
|---|---|
| 신전 | 기존 16×16u 구간과 문·구슬 위치를 유지했다. 밝은 사암 바닥과 열린 기둥, 목재 도구 받침을 배치했다. |
| 지킴이 | 단순한 원통과 원반을 얼굴·어깨·팔·발이 있는 석상으로 바꿨다. 가슴 앞에 실제 격자 형태의 체를 들고 있다. |
| 도구 | 색깔 보석을 체·말굽자석·거름종이 깔때기·작은 화로 모형으로 교체했다. 도구 선반과 혼합물의 무작위 순서는 유지한다. |
| 혼합물 | 쇠구슬과 모래, 콩과 좁쌀, 소금물, 모래 섞인 소금물을 구분해서 표시한다. 재료 이름은 알려 주지만 맞는 도구를 색이나 화살표로 연결하지 않는다. |
| 분리 결과 | 완료하면 서로 다른 고체 재료는 양쪽으로 나뉘어 보인다. 소금은 액체 상태에서 결정으로 미리 보이지 않고, 증발을 끝냈을 때 나타난다. |
| 두 단계 문제 | 모래 섞인 소금물은 거름 → 증발을 차례로 적용한다. 모래를 먼저 분리한 중간 상태도 별도로 표시한다. |
| 도구 재사용 | 한 그릇을 완성하면 도구가 선반으로 돌아간다. 같은 화로를 두 혼합물에 다시 사용할 수 있다. |
| 되돌리기 | 진행 중인 그릇에서 마지막 도구를 다시 꺼낼 수 있다. 장치가 없는 곳이나 이미 끝난 그릇 앞에서는 든 도구를 E로 선반에 반환한다. |
| 피드백 | 맞지 않는 도구는 손에 남는다. 이유를 보여 주는 동안에도 E 안내가 유지되어 모바일 조작을 막지 않는다. 순서가 틀리면 해당 그릇만 초기화한다. |

![모든 혼합물을 분리하고 눈을 뜬 지킴이](D:/mumumetro/reports/2026-09-09/evidence/sift-sanctum/after-solved.png)

네 그릇을 완성하려면 정상 경로에서 도구를 다섯 번 적용한다. 지킴이의 눈은 기존 방식대로 약 1.5초에 걸쳐 밝아지며, 구슬 낙하와 획득으로 이어진다. 완료한 재료는 그릇 주변에 남고 도구는 재사용 가능한 상태로 돌아온다.

## 이전 기록의 보존

개편 전에 단일 혼합물 하나를 완료하고 두 단계 혼합물에 거름 도구를 적용한 기록을 보관했다. 같은 상태에서 화로를 든 기록도 별도로 남겼다.

새 저장은 손에 든 도구, 각 도구가 설치된 그릇, 그릇별 완료 순서, 전체 완료 여부, 눈의 각성 정도를 기록한다. 옛 장면 노드를 새 모델에 덮어쓰지 않고 상태를 이관한다. 도구를 동시에 들고 설치한 기록이나 잘못된 단계 순서는 거부하며, 거부해도 현재 진행은 바꾸지 않는다.

옛 신전 안의 재개 좌표는 새로운 받침과 겹치지 않도록 입구로 옮긴다. 완료한 그릇·중간 단계·들고 있는 도구·힌트와 문은 유지한다. 이미 얻은 구슬은 재접속해도 다시 얻을 수 없다.

| 소스 | 106개 모듈, 271개 로컬 import, 19개 vendor 해시와 음악 경로 통과 |

전용·회귀 검사는 총 **99개**다. 외부 요청을 막은 독립 Edge 브라우저에서 실행했다. 보행은 실제 이동 입력으로 수행했지만 자동 검사 도구가 정답 순서를 알고 조향한다. 처음 하는 사람의 난이도·이해도·재미까지 검증했다는 뜻은 아니다.

같은 씨드와 입구 시점에서 전체 렌더 호출은 **422 → 491**, 삼각형은 **15,241 → 21,913**으로 증가했다. 새 도구와 재료를 추가한 비용이며 실제 기기의 프레임 속도 측정값은 아니다.

## 검토 중 수정한 판단과 한계

- 첫 석상 배치는 전체 카메라 검사에서 중앙 시선을 막았다. 지킴이를 3u 뒤로 옮기고 겹치던 기존 봉화·배경 구조를 제거해 그릇 뒤 여백을 확보했다.
- 이어서 무작위 배치의 셋째 방에서도 실패가 나왔다. 확인하니 공통 카메라 검사가 충돌을 비우고 깔때기 내부를 출발점으로 삼고 있었다. 같은 깊이에서 실제 보행 가능한 지점을 고르도록 수정했다. 후퇴 거리 85%와 파묻힘 금지 기준은 유지하며, 검사할 보행 지점이 없으면 실패로 기록한다.
- 레퍼런스의 도구 실루엣, 재료별 결과, 사암과 목재, 체를 든 지킴이는 반영했다. 실제 모델은 단순한 다면체이고 강한 황토색 조명도 남아 있다. 석상 모서리·손·옷 주름, 표면 질감, 자연스러운 조명은 후속 미술 개선 대상이다.
- 도구를 쓰면 재료 위치가 즉시 바뀐다. 실제 체질·붓기·여과·증발 동작과 유체·입자 물리는 이번 범위에 포함하지 않았다. 들고 다니는 화로도 분리 방법을 나타내는 게임용 모형이다.
- 좁은 모바일 화면은 가까운 그릇 위주로 보인다. 신전 전체를 한 화면에 담는 구도가 아니며, 사용자가 시점을 돌리며 살펴보는 방식이다.

다음 개선은 **분리 사당을 처음부터 끝까지 처음 하는 사람에게 플레이하게 하고, 도구 사용과 결과 변화 사이의 짧은 애니메이션을 보강하는 것**이다. 네 공간의 첫 개편 완료와 전체 앱의 최종 완성도는 구분해서 관리한다.
