# 분리 사당 셋째 방 — 거름과 증발

2026-09-09 · 로컬 적용 · 공개 사이트 미배포

**셋째 방을 자석·거름종이·화로가 구별되는 작업장으로 개편했다.** [승인된 분리 사당 시안](../2026-09-08/SIFT_REFERENCE.md)의 세 번째 패널을 기준으로 만들었다. 이제 분리 사당의 세 관문까지 적용했으며, 마지막 조합 신전은 다음 작업이다.

## 무엇이 달라졌나

| 요소 | 적용 내용 |
|---|---|
| 공간 | 기존 12×12u 방과 출입문 좌표를 유지하고 사암 바닥·기둥, 목재 작업대, 황동 테두리를 적용했다. |
| 도구 | 같은 모양의 발광 받침 세 개를 말굽자석, 종이 깔때기와 받침컵, 화로로 바꿨다. 섞이는 도구 위치와 기존 씨드는 유지한다. |
| 물통 | 위가 열린 도기와 손잡이, 액체 표면, 성분별 입자를 만들었다. 녹아 있는 소금은 결정으로 미리 표시하지 않는다. |
| 쇠가루 | 자석을 사용하면 물통 안 쇠가루가 사라지고 자석 끝에 붙어 보인다. |
| 모래 | 거름종이를 사용하면 물통 안 모래가 사라지고 종이 안에 모래가 쌓인다. |
| 소금 | 걸러진 소금물을 가열하면 액체 표시가 사라지고 흰 결정이 남는다. 완성된 물통은 화로 받침 위에 놓인다. |
| 다시 하기 | 거르지 않은 혼합물을 가열하면 실패 상태가 된다. 물꼭지로 돌아가 물을 부으면 처음부터 다시 할 수 있다. |
| 조작 | 가장 가까운 장치를 선택한다. 장치 밖에서도 E로 물통을 원래 받침에 돌려놓을 수 있다. 현재 단계에 맞지 않는 자석·거름종이 앞에서는 반환 안내와 동작을 일치시켰다. |
| 모바일 구도 | 기존 큰 안내판을 오른쪽으로 옮기고 크기를 줄여 작업대 앞 시야를 확보했다. 수첩 정지와 터치 E를 확인했다. |

기존 게임의 `mixed → demag → filtered → salt` 순서를 유지한다. 도구 이름을 외워 누르는 대신 도구 형상과 분리 후 남는 재료를 볼 수 있게 바꿨다. 세 단계를 한 번의 조작으로 합치지 않았다.

## 저장과 재개

개편 전에 거름을 마친 물통을 내려놓은 기록과, 같은 물통을 든 기록을 각각 보관했다. 새 저장은 메시 번호 대신 **혼합물 상태와 물통을 들었는지**를 기록한다. 옛 기록은 원래 형식의 유효성을 먼저 확인하고 새 모델에 옮긴다.

옛 셋째 방 안의 보행 좌표는 새 받침과 겹치지 않도록 입구 안전 지점으로 이동한다. 혼합물 상태·들고 있는 물통·힌트 시간·열린 문은 보존한다. 복원만으로 가열되거나 성공하지 않으며, 물통을 든 채 재접속한 뒤 실제로 화로까지 걸어가 완료할 수 있다.

## 실제 검증

| 검사 | 결과 |
|---|---|
| 셋째 방 전용 | 14개 통과 |
| 재료 표시 | 다섯 혼합물 상태에서 쇠가루·모래·소금 결정·액체·실패 덩어리 표시 확인 |
| 모래와 종이 | 모래 더미의 모든 꼭짓점이 종이 안에 있고, 두 원뿔 면의 최소 간격이 0.025u보다 큰지 측정 |
| 실제 보행 | 연결 통로에서 출발, 잘못 가열하기 → 물로 초기화 → 잘못된 거름 단계에서 반환 → 다시 들기 → 세 단계 완료 → 다음 문 통과 |
| 저장 | 옛 두 기록의 이관, 새 저장 재접속, 복원한 물통 사용, 소금을 든 불가능한 기록의 원자적 거부 |
| 카메라 | 여섯 조작 위치 × 세 높이 × 여덟 방향, 144개 시점에서 등록된 고체 장치와 시선 충돌 없음 |
| 모바일 | 수첩을 읽는 동안 상태·힌트 정지, 닫은 뒤 터치 E로 가열하여 한 번만 완료 |
| 결함 주입 | 소금 결정 표시를 강제로 숨긴 별도 브라우저에서 표시 오류 검출 |
| 앞 두 방 | 체 고르기 15개, 성질로 나누기 14개 회귀 검사 통과 |
| 공통 진행 | 사당 진행 42개 통과. A~W 23그룹 전부 실행 및 저장·실행 상태 보존 |
| 소스 | 103개 모듈, 265개 로컬 import, 19개 vendor 해시와 음악 경로 통과 |

전용 검사와 회귀 검사는 총 **85개**다. 외부 요청을 막은 독립 Edge 브라우저에서 수행했고, 실제 이동 입력과 E/터치 입력을 사용했다. 자동 검사 도구는 도구의 정답 순서를 알고 조향하므로 처음 하는 사람의 이해도나 재미를 검증한 것은 아니다.

같은 씨드와 입구 시점에서 전체 렌더 호출은 **526 → 546**, 삼각형은 **16,377 → 20,997**이었다. 도구 형상과 재료를 추가하면서 증가한 값이며, 실기기 프레임 속도 측정값은 아니다.

## 레퍼런스 대비 평가와 남은 작업

- 시안의 열린 깔때기·모래·도기·황동 구조를 반영했다. 실제 화면은 더 단순한 형태이며 황토색 조명이 강하다. 목재 결, 천막, 식물, 석재 마모와 부드러운 그림자는 추가 미술 작업이 필요하다.
- 처음에는 모래 더미와 종이의 원뿔 면이 거의 겹쳐 줄무늬가 생겼다. 모래의 반지름을 줄이고 실제 꼭짓점 간격 검사로 재발을 막았다. 화로 받침과 물통 바닥 높이도 맞췄다.
- 전경의 큰 안내판이 휴대전화 화면에서 작업대를 가렸다. 안내판의 위치·각도·크기를 조정한 뒤 화면을 다시 확인했다.
- 분리 조작은 즉시 상태를 바꾸는 기존 방식이다. 액체를 붓는 동작, 거름액이 떨어지는 흐름, 시간에 따라 줄어드는 수면과 증기는 아직 구현하지 않았다. 받침컵은 장치 형태의 일부이며, 거른 액체는 운반 물통 상태로 이어진다.
- 실패 상태는 기존 게임처럼 하나의 덩어리 상태로 단순화한다. 실패 이전에 따로 꺼낸 재료의 양과 이력까지 보존하는 물질 보존 시뮬레이션은 아니다. 정해진 세 단계 분리 문제이며 모든 순서를 자유롭게 실험하는 과학 실험실은 아니다.

다음은 **마지막 분리 신전**이다. 앞 세 방에서 배운 체질·자성·거름·증발을 혼합물 네 가지와 연결하고, 두 방법을 순서대로 조합하는 마지막 문제를 같은 미술 기준으로 개편한다.
