# Unity 퀘스트 안내와 수첩 주변 지도

화면 위 현재 퀘스트를 누르면 금빛 입자 경로와 방향·대략적인 거리가 나타난다. 다시 누르면 꺼진다. 범선에서는 소포 회수부터 출항까지 현재 단계에 따라 목적지가 바뀌고, 행성에서는 실제 무게의 신전 정문을 가리킨다. 수첩을 읽는 동안에는 경로가 사라진다. 안내 상태는 이 PC의 설정에만 남으며 퍼즐과 탐사 저장 상태를 바꾸지 않는다.

수첩에 네 번째 **주변 지도** 면을 추가했다. 행성 착륙지 주변의 방향도이며, 착륙 지점·플레이어 현재 위치·무게의 신전을 표시한다. 움직이면 플레이어 표식이 따라간다. 범선과 신전 안에서는 지도를 아직 쓸 수 없는 이유를 안내한다. 이 면은 웹 게임의 전체 지형 지도와는 범위가 다르다.

## 제작·검증

- 장면 갱신: `Mumu.Editor.BuildQuestGuide.CreateAndBuild`; 기존 행성·신전 장면의 수첩을 확장하고 범선 장면을 재생성했다.
- 렌더링: 부드러운 96개 금빛 입자를 한 Particle System으로 표시한다. 행성에서는 이동할 때 32개 지형 높이만 다시 읽고 그사이를 보간한다.
- Windows 실행판: `unity/check-quest-guide.ps1`에서 1440×900과 960×540 각각 18개 검사 통과. 퀘스트 버튼 클릭, 목적지 변경, 금빛 경로, 수첩 모달 중 숨김, 지도 페이지, 플레이어 표식 이동, 끄기 동작을 확인했다.
- 기존 범선 도입부 36개 검사와 별도 실행 복원 4개 검사 통과. 수첩 회귀 검사는 1440×900·960×540·1920×868에서 각각 1,179개 통과했다.
- 화면 확인: [범선 금빛 경로](unity-quest-guide-optimized/1440x900/01-ship-gold-path.png), [행성 신전 안내](unity-quest-guide-optimized/1440x900/03-planet-gold-path.png), [수첩 주변 지도](unity-quest-guide-optimized/1440x900/04-notebook-local-chart.png), [작은 창 지도](unity-quest-guide-optimized/960x540/04-notebook-local-chart.png).

신전 내부 퍼즐에는 기존 방별 안내 UI를 유지했다. 닫힌 문 너머로 금빛 경로가 지나가는 잘못된 안내를 피하기 위해 이번 단계의 입자 경로는 범선·착륙지 주변에만 적용했다.
