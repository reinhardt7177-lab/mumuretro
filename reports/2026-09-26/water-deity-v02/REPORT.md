# 물의 신 V02 적용 결과

Blender에서 새 신상 모델을 생성하고 Unity 성소의 V01 모델을 V02로 교체했다. 기존 원본과 퍼즐·대화·저장 로직을 유지했다.

## 변경

- 얼굴 윤곽·눈꺼풀·코·입술, 손가락과 엄지, 다층 로브와 늘어진 소매, 곡면 어깨 망토, 머리카락, 왕관과 후광을 제작했다.
- 첫 실행 캡처에서 어깨 테두리가 막대처럼 보이는 문제를 확인하고 곡면 망토로 수정했다.
- 부드러운 코너 법선을 유지하는 전용 JSON 내보내기를 적용했다. 중복 정점을 합치고 수치를 소수점 여섯 자리로 기록했다.
- 최종 164,564 삼각형, 9 재질 묶음, JSON 8,595,843바이트. 프레임 성능은 측정하지 않았다.
- 기존 일회성 반사 캡처 컴포넌트로 성소에 128px 반사 프로브를 추가했다.

## 검증

- Blender 4.5.3 원본 생성 성공.
- Unity 6000.0.84f1 성소 재생성 및 Windows 빌드 성공, 종료 코드 0.
- 최종 빌드 성소 자동 검사 10개 통과: 입장, 실제 통로 보행, 대화 거리, 이동 잠금, 연속 입력 방지, 수첩 중 대화 차단, 대화 진행 및 이동 복구.
- 실제 빌드 `final/deity-audience.png`를 육안 확인했다. 캡처 카메라 구도이며 AI 시안이 아니다.

## 남은 차이

시안의 세밀한 얼굴 조형, 직물 질감, 자연스러운 머리카락까지 동일하게 구현한 상태는 아니다. 현재는 정적 메시이며 리깅·표정·의상 애니메이션은 없다. 이번 변경은 신 모델 개선으로, 보상·귀환·봉인 기능은 추가하지 않았다.
