# 물의 신 성소 — 다음 장면 연결

## 변경

- 별도 Unity 장면 `WaterSanctuary`를 생성했다. 기존 Blender 성소와 물의 신 모델을 가져오고, 보행 바닥·물가 경계·단상 계단에 충돌체를 배치했다.
- 마지막 방의 완료 저장 후 자동으로 성소에 이동한다. 기존 세 방 저장 형식은 유지한다.
- 중앙 통로를 따라 신 앞에 접근한 뒤 E로 세 줄의 대화를 진행한다. 대화 중 이동을 잠그고, 종료 시 해제한다. 수첩은 대화 진행을 차단한다.
- 기존 세 방 자동 검사와 별도로 성소 입장·보행·대화 및 실제 캡처 검사를 추가했다.

## 남은 범위

영구 보상·수첩 완료 기록·행성 귀환·신전 봉인은 아직 연결하지 않았다. 이번 구현은 다음 장면과 첫 만남이다. 모델은 초기 구현이며 레퍼런스와 동일한 최종 품질을 달성했다고 주장하지 않는다.

## 검증 결과

- Unity 전체 장면 생성 및 Windows 빌드 성공(종료 코드 0).
- 성소 직접 입장: 보행·거리 제한·대화 잠금·연속 입력 방지·수첩 중 대화 차단·종료 후 이동 해제 등 10개 검사 통과.
- 기존 세 구간과 저장 복원: 32개 검사 통과.
- 완료 기록 복원 후 `EnterSanctuary` 장면 전환과 성소 동작: 10개 검사 통과. 자동 대기 시간 자체를 재는 검사는 아니다.
- 실제 빌드의 입장 전경과 신 대화 화면을 캡처하여 확인했다. 캡처용 카메라 구도이며 일반 플레이 카메라의 사용자 조작 검증이나 성능 측정은 아니다.
- 테스트는 별도 JSON 저장 경로를 사용했다.

증거: `direct/sanctuary-result.json`, `from-completion/sanctuary-result.json`, `journey/` 및 각 폴더의 `player.log`.
