# 물의 신 V03 마무리 검수

상태: 물의 신 V03 아트 적용과 Windows 실행 검수 완료. 게임 전체 완성을 뜻하지 않는다.

## 제작 결과

- 승인된 정면 시안으로 Meshy 모델을 1회 생성했다. 사용 기록은 40크레딧이며 추가 생성은 하지 않았다.
- 원본 GLB와 고밀도 조각을 보존하고, Blender에서 높이 3.3m·바닥 기준·방향·UV·텍스처 연결을 정리했다.
- 얼굴을 원본 고밀도 조각에 맞춰 보완했다. 본체 147,977삼각형, 별도 후광·물방울 25,856삼각형, 물방울 내부 코어 2,560삼각형으로 장면 내 합계 176,393삼각형이다.
- 8K 색상 원본을 보존하고 Unity에서는 최대 4K 텍스처와 밉맵을 사용한다. 금속·거칠기 채널은 Unity 형식으로 변환했다.
- 단상 Y=0.45m에 모델 밑면을 맞추고 기존 접근·대화·수첩 동작을 유지했다.

## 확인한 사항

최종 Blender `asset-qc.json`에서 실제 높이 3.30000019m, 바닥 Z=0, 유한 좌표, UV와 내장 텍스처 4개를 확인했다. 이전 노멀맵과 새 2K 맵을 함께 보존한다.

9월 26일 Windows 캡처의 정면·양측면·후면에서 큰 구멍, 뒤집힌 방향, 분리된 조각, 후광의 인체 관통, 단상 위 공중 부양은 보이지 않았다. 입구에서 중앙 통로와 계단도 확보됐다.

기존 실행 JSON의 대화 검사 10개는 통과했다. 다만 당시 검사 스크립트는 종료 대기 60초를 넘겨 실패했으므로, 이를 최종 전체 실행 성공으로 취급하지 않는다. 다각도 캡처를 포함한 대기 시간을 180초로 조정했다.

## 음영 수정

기존 머티리얼, 노멀맵 끔, 그림자 끔, 둘 다 끔의 네 화면을 비교했다. 그림자를 꺼도 얼굴·목의 삼각 자국은 남았지만 노멀맵을 끄면 거의 사라졌다. 얼굴 보완 후 메시와 기존 맵의 표면 기준이 맞지 않는 문제로 판단했다.

`bake_water_deity_v03_normals.py`가 보존된 고밀도 조각을 최종 메시의 UV와 법선 기준으로 다시 베이크했다. 2048², tangent +X/+Y/+Z, 여백 12px이며 Unity 강도는 1이다. 소요 시간 26.84초는 이번 PC의 제작 과정 기록이며 게임 성능 수치가 아니다. 수정 화면에서 뺨·입가·목의 큰 삼각선이 사라지고 의상 표면 디테일은 유지됨을 확인했다. 전체 그림자를 끄는 변경은 하지 않았다.

물방울은 별도 URP 재질을 사용한다. 맑은 청록 외피(알파 0.34, 매끄러움 0.94)와 28% 크기 내부 코어를 사용하며, 새 조명·콜라이더·프레임별 갱신은 추가하지 않았다. 투명 물체의 불투명 그림자만 비활성화했다. 실제 굴절 시뮬레이션은 아니다.
