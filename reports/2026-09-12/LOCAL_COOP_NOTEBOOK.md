# 로컬 저장·3인 협동 방향 및 수첩 개선

2026-09-12 사용자 결정: 계정 연결과 개인 클라우드 저장 개발 중단. 로컬 진행 유지. 최대 3명 임시 협동 방은 후속 개발. 기존 Supabase 게임 저장 객체는 삭제하지 않으며 현재 게임에서 사용하지 않는다.

이번 변경: 메인 플레이 HUD 수첩 버튼에 글자 라벨, 금빛 배경, 넓은 터치 영역 적용. 기존 수첩 획득 조건 유지. 수첩 본문 17px, 질문 21px(좁은 화면19px), 밝은 무늬 없는 종이와 짙은 본문색 적용. 작은 화면에서 글자를 줄이지 않고 스크롤 허용.

협동 미구현: 익명 세션 발급, 최대 3인 방 생성/입장, 서버가 결정하는 상자 소유권과 퍼즐 상태, 연결 종료 처리, 각 기기 보상 기록은 아직 연결되지 않았다. 기존 Supabase 프로젝트의 익명 인증 활성화는 다른 프로그램에도 영향을 줄 수 있으므로 게임 전용 세션 서버 또는 별도 프로젝트와 비교해 결정해야 한다. 수첩 UI 변경을 멀티플레이 완료로 표시하지 않는다.
