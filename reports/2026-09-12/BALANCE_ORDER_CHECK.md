# 첫 무게 퍼즐 3개 완료 후 이동 점검

사용자 제보: 3개 모드를 완료해도 다음 방으로 넘어가지 못함.

## 확인한 사실

수정 전 로컬 코드에서 3·4·5개를 각각 실제 상호작용 입력으로 선택하고, 가벼운 순서대로 집어 배치한 뒤 문을 열고 두 번째 방까지 걸어가는 검사는 모두 통과했다. 선택 개수보다 많은 상자를 요구하는 조건은 없었다. 사용자에게 발생한 동일 증상의 원인은 아직 확인되지 않았다.

기존 검사는 개수 선택만 3·4·5개로 확인하고 실제 문 통과는 5개에서만 확인했다. 이번에 모든 개수의 실제 배치·문 통과·저장 복원을 검사하는 `tools/check-balance-order-counts.cjs`를 추가했다.

## 보강

- 출구 앞 상태판에 선택 개수, 배치 수, 순서 불일치, 성공 여부를 표시한다.
- 3/3 배치라도 순서가 틀리면 성공과 구분해 안내한다. 정답 상자의 무게는 공개하지 않는다.
- 마지막 상호작용 시점 외에도 업데이트에서 실제 배치를 다시 확인한다. 올바른 배치와 미갱신 판정이 공존하면 정상 성공 판정으로 회복한다.
- 저울의 두 접시는 정답 받침으로 세지 않으며, 선택하지 않은 상자는 성공에 요구하지 않는다.

이 변경을 사용자 제보의 확정 원인 수정이라고 주장하지 않는다. ‘문이 닫혀 있는지 / 열린 문에서 이동이 막히는지 / 상자 배치만 끝났고 순서 판정은 실패인지’의 구분이 추가로 필요하다.

검증 결과와 화면: `evidence/balance-order/`.

## 추가 확인 및 물의 사원 입구 변경

사용자는 문 자체가 계속 닫혀 있다고 확인했다. 완료된 퍼즐의 문 상태만 초기화한 회귀 검사에서, 매 프레임 문 열림을 동기화하는 변경으로 통과 상태가 회복됐다. 최초 제보의 정확한 발생 경로는 여전히 확인되지 않았다.

물의 사원 야외 해빙 장치를 장면에서 제거하고 상호작용·충돌·업데이트를 비활성화했다. 포털은 바로 입장 가능하며 기존 물길 저장 데이터는 호환을 위해 유지한다. 신전 내부 퍼즐은 유지한다.

검증: 3/4/5 실제 배치·문 통과·저장 복원, 잘못된 순서 차단, 완료 상태의 닫힌 문 복구, 미해빙 상태에서 실제 입장 입력, 기존 물길 데이터 복원, 소스 검사 모두 통과. `tools/check-direct-water-entry.cjs`와 `evidence/balance-order/entry-check.json` 참조.
