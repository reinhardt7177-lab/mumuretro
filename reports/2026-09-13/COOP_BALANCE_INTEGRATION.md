# 균형 협동 게임 연결

설정 → 방 만들기/코드 참여 → 균형 신전 함께하기. 3명 같은 고정 seed의 독립 방을 생성한다. 기존 rooms map의 개인 균형 방은 보관 후 퇴장 시 복구한다. 협동 중 saveProgress는 쓰기를 거부한다. 협동 완료는 개인 완료 플래그를 갱신하지 않는 실험 모드이며 정식 참여 보상 저장은 후속 작업이다.

서버의 세 단계 상태를 실제 CarryTrial 장치에 적용한다. 상호작용은 서버 명령으로 전환하고 정답은 서버 결과로만 판정한다. 늦게 도착한 낮은 revision은 무시한다. 상대가 든 상자는 원래 위치에 남기지 않도록 숨긴다(손에 붙여 표시하는 연출은 미구현). 신전 위치는 balance 채널로 공유한다.

현재 로컬 검증판이다. 별도 PC 접속/공개 HTTPS 서버 배포, 이동 및 상호작용 거리의 서버 검증, 명령 재전송 중복 방지, 캐릭터 복제, 정식 완료 보상은 미완료다. 기존 Supabase 객체/로그인 설정은 수정하지 않았다.

검증 완료: 독립 브라우저 3개에서 UI로 방 생성/참여/협동 신전 입장. 실제 장치 interact 호출로 각자 상자를 들고 놓아 첫 방 완료 상태와 문 rect.open이 세 클라이언트에서 일치함을 확인. 협동 중 game.save(true)=false와 퇴장 확인. 키보드로 전 구간 이동한 검사는 아니며 안내 창은 테스트에서 닫고 프레임을 진행했다. 서버 세 단계 판정, HTTP 소유권 검사, 기존 로컬 저장 검사도 통과.
