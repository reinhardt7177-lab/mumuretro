# Unity 초원 바람 효과

시작 초원에 가느다란 풀잎을 추가하고, 뿌리를 고정한 채 끝부분이 바람에 흔들리도록 구현했다. 현재 적용 범위는 시작 위치에서 약 40m이며 행성 전체 배치는 아니다.

## 구현

- 원본 지형·잔디 표면을 따라 총 126,373개 풀잎을 177개 메시 구역으로 생성한다. 개별 풀잎 GameObject는 만들지 않는다.
- 풀 높이·폭·색·방향을 변주하고 공간상으로 이어지는 바람과 약한 개별 흔들림을 합성한다.
- 원본 흙길, 신전 발판, 시작 위치에서 발판까지의 접근로와 자연물 충돌 영역을 비운다. 풀밭 경계의 밀도를 점차 낮춘다.
- 27~36m 거리에서 풀잎을 서서히 줄이고, 먼 구역은 그리지 않는다. 변형을 고려해 메시 경계도 확장했다.
- 풀의 전방 렌더링과 깊이 렌더링에 동일한 변형을 적용한다. 그림자를 받지만 개별 풀 그림자는 생성하지 않는다.
- 기존 지형 충돌과 캐릭터 애니메이션은 유지한다. 이번 구현에는 캐릭터가 풀을 밀어내거나 밟는 효과는 포함하지 않았다.

## 확인 결과

- Unity 6000.0.84f1 Windows 빌드 성공.
- 실제 렌더링에서 바람 시간만 바꾼 두 화면 사이 132,447개 픽셀의 변화 확인. 동일한 시간으로 반복 렌더링한 화면은 허용 오차 안에서 일치했다.
- 풀잎 뿌리의 바람 가중치 0, 끝부분 가중치 1, 풀 자체 충돌체 없음, 셰이더 지원 확인.
- 기존 탐사 회귀 검사 54개 통과: 걷기, 정지 후 재출발, 방향 전환, 달리기, 점프, 착지 등.
- `wind-a.png`, `wind-b.png`를 직접 확인했다. 첫 결과의 넓은 풀잎과 각진 경계를 개선한 최종 화면이다.
- 거리별 표시량 제어를 넣었으나 기기별 FPS 벤치마크와 WebGL 검증은 이번 범위에 포함하지 않았다.
