# 은빛 이삭과 바람 물결

고스트 오브 쓰시마의 풀밭에서 참고한 것은 풀 군락의 밀도, 은빛 이삭, 넓게 지나가는 바람의 흐름이다. 게임의 에셋을 복사하지 않고 현재 Unity 초원 생성기와 셰이더를 확장했다.

## 변화

- 낮은 풀과 키 큰 풀, 약 0.8~1.1m 이삭 줄기를 섞는다. 공간 노이즈로 키 큰 풀의 군락을 만들며 길과 신전 입구를 보존한다.
- 이삭은 교차한 두 면에 깃털 모양과 미세한 섬유 윤곽을 셰이더로 표현한다. 줄기와 같은 뿌리·위상을 사용해 함께 흔들린다.
- 큰 공간 노이즈가 바람 방향으로 이동하고, 작은 물결과 잎별 움직임이 겹쳐진다. 키 큰 풀은 더 크게 휘고 뿌리는 고정된다.
- 잎 끝의 밝기와 약한 역광 투과 느낌을 추가해 풀밭에 깊이를 준다.
- 기존 거리 표시 제어와 충돌 영역은 유지한다. 바람 변형 범위에 맞춰 메시 경계를 확장했다.

## 범위

시작 지역 약 40m에 적용한다. 플레이어가 풀을 밀어내는 효과, 행성 전체 군락 생성, WebGL 성능 검증은 포함하지 않는다. 이번 수정은 Unity 로컬 Windows 빌드 대상이다.

## 검증 자료

`unity/check-meadow.ps1 -OutputDirectory ./reports/2026-09-20/unity-pampas`로 생성한 결과와 화면을 같은 폴더에 보관한다.

- Unity 6000.0.84f1 Windows 빌드 성공. 풀 204,622개와 이삭 11,637개를 179개 구역에 생성했다.
- 최종 풀 표현 검사 통과: 뿌리 가중치, 이삭 연결, 충돌체 없음, 셰이더 지원 및 실제 렌더링에서 바람 시간별 변화 확인.
- 두 바람 시점에서 223,686개 픽셀의 변화가 관측됐고 동일 시점의 반복 렌더링은 허용 오차 안에서 일치했다.
- 이동·방향 전환·점프·착지 등 탐사 회귀 검사 54개 통과.
- 화면을 직접 확인한 뒤, 이삭의 폭과 밝기를 낮추고 섬유 사이를 비웠다. 풀잎은 세 구간으로 나눠 굽힌다.
- FPS 벤치마크는 수행하지 않았다. 구역별 거리 제어는 유지하지만 기기별 성능은 별도 측정 대상이다.
