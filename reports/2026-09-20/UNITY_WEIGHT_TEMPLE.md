# Unity 무게의 신전 첫 방

## 이번 범위

기존 행성 탐험에서 무게의 신전 입장 → 상자 비교 → 가벼운 순서로 배치 → 첫 문 열림 → 문 통과 → 행성 복귀를 연결한다. 두 번째 균형 방, 마지막 지렛대, 신과의 만남, 수첩·저장·협동은 이 단계에 포함하지 않는다.

## 기존 웹 규칙의 이식

- 원본: `src/shrine/BalanceTrials.js`의 `BalanceOrder`, `src/data/balanceTemple.js`, `tools/check-balance-temple.cjs`.
- 3·4·5개 선택. 선택을 바꾸면 현재 배치와 들고 있는 상자를 초기화한다.
- 무게 숫자는 표시하지 않는다. 서로 다른 크기와 문자 표식으로 상자를 구별하며, 저울은 무거운 쪽이 내려간다.
- 왼쪽 첫 받침대부터 가벼운 순서로 선택한 상자만 배치하면 문이 열린다. 비교용 접시는 정답 받침대로 계산하지 않는다.
- 완료 뒤 난이도는 잠기며, 명시적인 ‘다시 놓기’로 새 도전을 시작한다.

## 구성

- 원본 Blender v04와 GLB를 보존하고 `tools/blender/export_unity_balance.py`로 첫 방·저울·상자·받침대·문을 FBX로 변환했다.
- `BalanceOrderState`가 위치·소유·완료 조건을 단독 관리한다. UI와 애니메이션은 이 상태를 표시한다.
- 기존 캐릭터 이동에 평면 바닥 모드를 추가하고, 기존 행성의 구면 이동은 유지한다.
- 상자 소지 중 걷기 속도를 줄이고 점프는 막는다. 두 손은 실제 상자 손잡이 위치를 따라간다.
- FBX의 내부 축·스케일은 유지하고 Unity 미터 단위의 빈 부모를 추가했다. 저울 가로대와 접시는 별도 회전축으로 분리하여, 게임에서 지정한 높이와 회전 방향이 실제 부품과 맞도록 했다.
- E로 집기·받침대에 놓기, Q로 바닥에 내려놓기. 가까운 대상에 따라 안내가 바뀐다.
- 나눔고딕 정적 TMP 글꼴과 uGUI 사용. [Google Fonts 원본](https://github.com/google/fonts/tree/main/ofl/nanumgothic), 동봉 OFL 라이선스는 `Assets/Mumu/Fonts/OFL.txt`에 보존한다.

## 재생성·검증

Unity 에디터 메서드 `Mumu.Editor.BuildWeightTemple.CreateAndBuild`는 현재 행성 장면에 입장 표식을 추가하고 별도 `WeightTemple` 장면을 생성한다. 기존 자연물·캐릭터 원본을 다시 생성하지 않는다. 신전 장면은 생성 자산이므로 수작업으로 변경할 때는 먼저 복제한다.

`unity/check-temple.ps1`은 독립 실행판에서 입장, 상자 소유 충돌, 오답, 들기·내려놓기·다시 들기, 저울 기울기, 3·4·5개 각각의 문 통과, 행성 복귀를 검증한다. `unity/check.ps1`로 기존 탐험 이동의 회귀도 확인한다.

완료 결과와 화면은 실제 실행 후 아래에 기록한다.

## 완료 결과

- Unity 6000.0.84f1 Windows 최종 빌드 성공.
- 첫 방 검사 **164개 통과**: 실제 UI 클릭, 닫힌 문 충돌, 들기·내려놓기·다시 들기, 난이도 변경 중 상자 반환, 무거운 쪽으로 저울 기울기, 3·4·5개 각각의 정답 문 통과, 행성 복귀.
- 상자 소지 자세에서 양손과 손잡이 사이 오차가 출력 정밀도 기준 각각 **0.000**이었다. 실제 소지 화면도 확인했다.
- 기존 탐험의 걷기·정지·방향 전환·재출발·점프·착지·능선 이동 **54개 검사 통과**.
- 첫 화면·상자 소지·저울 비교·문 열린 화면을 직접 확인했다. 첫 카메라가 벽에 붙는 문제를 입구 통로로 개선하고 중복 안내문을 제거했다.
- `unity-weight-temple/result.json`, `player.log`, PNG와 `exploration-regression/`에 근거를 보존한다. 실행 로그에 예외나 글꼴 누락 오류는 없었다.
- `unity/build.ps1`의 재생성 경로도 행성 생성 후 신전 생성·빌드까지 이어지도록 갱신했다. 이번 실행 검증은 동일한 신전 생성 메서드를 직접 호출한 최종 빌드에 대해 수행했다.

현재 두 번째 방 이후와 저장·협동은 연결하지 않았다. ‘행성으로’ 돌아갔다 다시 입장하면 첫 방은 새로 시작한다.
