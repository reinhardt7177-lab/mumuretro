# Unity 첫 탐험 구간 이식

기존 웹 게임을 유지하면서 `unity/MumuPlanet`에 별도 프로젝트를 만들었다. 전체 게임 전환 완료가 아니라, 실제 실행 가능한 첫 탐험 구간이다.

## 구현

- Unity **6000.0.84f1**, URP, 새 Input System, Windows 64비트 실행판.
- 기존 지형 82,140개 정점과 잔디 표면을 그대로 추출했다. 반지름 68, 캐릭터 키 약 1.5 기준이다.
- 시작 구역의 자연물 1,117개와 충돌 영역 547개를 옮겼다. 원본 배치와 개별 색상을 보존하며 색상은 공용 머티리얼 묶음으로 양자화한다.
- Blender에서 항해사와 대기·걷기·달리기를 FBX로 변환했다. 본 24개와 스킨을 보존한다.
- 구면 중력 방향, 걷기·달리기, 입력 버퍼가 있는 점프, 자연물 충돌, 카메라 회전·줌·충돌 회피를 구현했다.
- 점프 관절 보정은 이동 계산과 분리했다. 원본 수첩·망원경·상자 동작은 아직 연결하지 않았다.
- 장면, 메시, 머티리얼, Animator Controller는 Unity Editor API로 생성한다. 재현 명령은 `unity/build.ps1`, 실행 검사는 `unity/check.ps1`이다.

## 검증과 수정

Unity 에디터 C# 컴파일과 Windows 빌드를 실행했다. 테스트는 빌드된 실행 파일에서 수행한다. `unity-exploration/result.json`, 실행 로그와 PNG가 증거다.

최종 실행 결과: **21개 검사 통과**, 실행판 종료 코드 0. 최종 실행 로그에서 예외·셰이더 오류가 발견되지 않았다. 지형·캐릭터를 실제 렌더링한 세 장의 화면을 확인했다. 수작업 키보드 조작 검증이나 전체 게임 완료 검사는 아니다.

검사 범위:

- 정지 시 지면 유지, 점프 최고 높이 약 **0.95**, 원래 지면으로 착지.
- 기존 능선 길 다섯 지점의 실제 이동과 구면에 맞는 캐릭터 위쪽 방향.
- Animator 연결과 달리기 시 스킨 정점 변형.
- 카메라 거리, 점프 관절 연결, 블렌더 뼈대 조작용 메시 제외.
- 착륙 위치·점프·전망대 화면 확인.

첫 화면 검사에서 카메라 방향의 런타임 초기화 누락과 FBX에 포함된 숨김 뼈대 핸들을 발견해 수정했다. 수치 검사가 통과해도 화면이 정상이라는 뜻은 아니었다. 이후 실제 스킨 발 위치에 맞춘 접지, 스킨의 화면 밖 갱신, 반전된 FBX 좌표에서의 관절 보정, 개별 자연물 색상을 보완했다.

## 현재 한계

- 학생 PC에서의 직접 조작·성능 측정과 WebGL 빌드는 아직 확인하지 않았다.
- 우주 범선 도입부, 착륙대·탐험 장치, 수첩·퀘스트 UI, 금가루 안내선, 여섯 신전, 로컬 저장, 협동 플레이는 아직 웹 버전에 있다.
- 시작 구역 외 자연물 배치와 원본 하늘·풀 흔들림·지면 잔결 효과는 다음 이식 대상이다.
- 현재 점프는 절차적 포즈다. 전용 점프·착지 클립과 소품 IK를 연결하는 애니메이션 작업이 남았다.
- 대기 시 팔 자세와 공중 동작, 하늘·조명은 이식용 초기 표현이다. 최종 아트 품질로 확정하지 않았다.
- 기존 웹 저장 데이터와 Unity 사이의 변환은 구현하지 않았다.
- GitHub 업로드와 Vercel 배포는 이번 Unity 초기 이식에서 실행하지 않았다.
