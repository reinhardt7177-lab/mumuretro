## 실제 적용

| 영역 | 변경 |
|---|---|
| 숲 | Blender로 줄기 결·밑동·갈라지는 가지를 제작. 수관은 일곱 덩어리, 넓은 나무와 좁은 나무 두 종류. 잎에는 부드러운 법선과 상·하부 색을 적용 |
| 바위 | 균일한 덩어리를 두 종류의 깨진 면·이끼 색이 있는 바위로 교체 |
| 덤불 | 네 덩어리의 낮은 관목으로 교체. 머리와 이동 시야를 가리지 않는 높이 유지 |
| 탐사길 | 기존 길가 돌을 낮은 석재 세 조각으로 교체. 길 가운데는 유지 |
| 착륙 지점 | 낮은 석재 테두리와 황동 방위 눈금 추가. 귀환 원과 효과는 유지 |
| 잔디·흙 | 구면 좌표를 사용하는 표면 잔결 추가. 먼 곳에서는 옅어져 깜박임을 줄이고 낮은 화질에서는 비활성화 |

## 게임 규칙과 성능

지형 높이·탐사 경로·채집 및 신전 위치·저장 형식은 변경하지 않았다. 같은 시드와 제외 구역으로 기존 산포 위치를 유지한다. 새 나무의 가지는 머리 위에 두고, 바위는 기존 지상 충돌 반경 안에 맞췄다. 충돌 높이는 기존/신규 모델을 모두 감싸도록 계산해서 화질을 바꿔도 판정이 달라지지 않는다.

- 새 GLB: **234,864바이트**. 외부 이미지 텍스처를 사용하지 않는다.
- 높음·중간: Blender 자연물. 낮음·가장 낮음: 기존 가벼운 모델.
- 셀별 인스턴싱 유지: 메시 139개, 인스턴스 12,504개, 충돌체 4,972개. 화질을 바꿔도 개수와 배치가 유지된다.
- 삼각형 수는 증가한다. 종류별 개별 모델은 줄기 20→232, 수관 60→140, 바위 20→80, 관목 60→80이다. 실제 화면의 FPS나 전체 드로우 콜을 의미하지 않는다.
- 태블릿 실기기에서의 지속 FPS·발열 검증은 포함하지 않았다.

## 검증

[자동 검사 결과](planet-detail/report.json) · [검사 코드](../../tools/check-planet-detail.cjs)

1. 첫 착륙 지점에서 능선길과 낮은 들길의 모든 경유지를 실제 이동 입력으로 통과했다. 경로 검사는 플레이어 좌표를 직접 옮겨 통과시키지 않는다.
2. 착륙 지점·숲·바위·관측대·수로 다섯 곳을 별도 촬영하고 화면을 확인했다. 촬영용 시점 이동은 보행 검증과 구분한다.
3. 높음→가장 낮음→높음 전환 시 메시 형상이 교체되고 원상 복귀하는지, 인스턴스 수와 충돌 데이터가 그대로인지 확인했다.
4. 새 자연물의 정점 색과 GLB 로드, 지면 셰이더 컴파일을 확인했다. 최종 검사에 JavaScript·셰이더 오류가 없다.
5. 소스 134개 모듈, 338개 로컬 import, vendor 19개 해시 검사 통과.

기존 `check-expedition.cjs`는 시작 UI 대기에서 실패했고, 제거된 수로 온열기 퍼즐을 검사하는 내용도 남아 있어 이번 완료 근거로 사용하지 않았다. 현재 시작 UI와 탐사 경로를 대상으로 하는 위 검사에서 필요한 보행·표시·화질 전환을 검증했다. 신전 내부 퍼즐 전체나 모든 저장 상태를 다시 검증했다는 뜻은 아니다.
