# 물의 신 최종 품질 검수 기준

범위: 승인된 V02 시안을 기반으로 한 물의 신 모델과 Unity 성소에서의 표현. 보상·귀환·봉인 개발은 이 아트 작업에 포함하지 않는다.

## 외형

- 자연스러운 성인 얼굴 비율과 눈꺼풀·코·입술·귀가 근접 화면에서 구분된다.
- 청록 겉 로브·아이보리 속 로브·소매가 큰 주름과 겹침으로 읽힌다.
- 금색 물결 문양, 허리 보석, 어깨 장식, 은빛 머리카락이 시안의 정체성을 유지한다.
- 몸과 분리한 후광·물방울의 위치가 인체를 관통하지 않는다.
- 정면·3/4·측면·후면에서 큰 구멍, 단절, 튀어나온 조각과 잘못된 방향이 없다.

## 엔진

- 밑면을 단상 Y=0.45m에 맞추고 보행 통로를 침범하지 않는다.
- 색·노멀·금속·거칠기 정보를 정확한 채널과 색 공간으로 연결한다.
- 원본 8K 텍스처는 보존하고 게임에서는 최대 4K와 밉맵을 사용한다.
- 플레이 거리에서 얼굴과 의상이 과노출되거나 배경에 묻히지 않는다.
- 기존 근접 대화·수첩·이동 잠금/복구가 유지된다.
- 실제 Windows 빌드의 다각도 캡처로 검수한다. AI 시안이나 제공업체 미리보기만으로 적용 완료를 판정하지 않는다.

## 증거

Blender 편집 원본, 공급업체 생성 이력, 기하 검사 JSON, Unity 빌드 로그, 실행 검사 JSON, 실제 캡처, 최종 차이/제한 보고서를 함께 남긴다.

Meshy 1회 생성: 정면 이미지 업로드와 약 40크레딧 사용을 사용자가 명시 승인했다. 작업 ID를 보존하여 상태 확인 실패나 시간 초과로 중복 접수하지 않는다.
