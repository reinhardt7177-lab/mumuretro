# 물의 신과 만나는 마지막 성소

## 제작 기준

`reference.png`는 내장 이미지 생성 도구로 만든 목표 시안이며 실제 게임 화면이 아니다. 중앙 마른 통로, 양옆 수면, 빙하 창, 석주와 아치, 청록색 예복·청동 후광의 물의 신을 기준으로 Blender 모델을 제작했다.

| 요소 | 게임 좌표·치수 |
|---|---|
| 성소 | X=-6..6, Z=0..14, 바닥 Y=0 |
| 중앙 통로 | X=-1.5..1.5, Z=2..10 |
| 입장 위치 | (0, 0, 1) |
| 대화 지점 | (0, 0, 9), 반경 2m |
| 단상 | 중심 (0, 0.225, 12), 높이 0.45m |
| 물의 신 | 발밑 (0, 0.45, 12), 본체·후광 포함 약 3.5m |

## 이번 연결

마지막 퍼즐의 완료 기록을 저장한 뒤 1.5초 후 `WaterSanctuary` 장면으로 이동한다. 완료 기록으로 다시 실행해도 성소로 들어간다. 중앙 통로를 걸어 신 앞에서 E를 누르면 3개 대사를 읽을 수 있다. 빠른 연타로 대사가 넘어가지 않으며, 수첩을 열면 대화 진행을 막는다. 대화가 끝나면 같은 방문 중에는 반복하지 않고 자유롭게 둘러볼 수 있다.

## 원본과 후속 범위

- `water-sanctuary-v01.blend`: 건축 원본.
- `water-deity-v01.blend`: 물의 신 원본.
- 생성 스크립트: `tools/blender/build_water_sanctuary_v01.py`.
- 보상·수첩의 영구 완료 기록·자동 귀환·외부 신전 봉인은 이번 장면 연결에 포함하지 않았다. 현재 대화 완료 상태는 방문 중에만 유지된다.
