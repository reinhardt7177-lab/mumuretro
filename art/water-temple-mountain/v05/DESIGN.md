# 태양 절벽 v05 · 360도 제작 설계

## 수정 기준
이전 모델의 문제는 세 개의 큰 평평한 층과 규칙적 지층이다. v05는 하나로 이어지는 비대칭 암봉으로 바꾼다. 등반 면은 남쪽, 좁은 길은 동쪽, 완만하게 올라오는 주 능선은 북쪽, 깊은 세로 침식골은 서쪽이다.

## 방향별 설계
| 뷰 | 반드시 보여야 하는 구조 | 피할 형태 |
|---|---|---|
| 정면 · 남쪽 | 하부 수직 등반, 오른쪽 횡이동, 도약 틈, 첫 쉼터 | 동일한 벽돌 쌓기 |
| 우측 · 동쪽 | 바위 몸체에서 이어지는 좁은 오르막과 안전 쉼터 | 떠 있는 보드·기둥 |
| 후면 · 북쪽 | 하부부터 정상까지 연속된 경사 암반과 비대칭 능선 | 장식 없는 뒷벽 |
| 좌측 · 서쪽 | 큰 침식골 2개와 굵기가 다른 수직 암반 | 원통형 링과 반복 주름 |
| 평면 | 전후 비대칭 외곽, 동쪽 등반 동선, 작은 정상 공간 | 동심원 3단 구조 |
| 아래 | 땅에 묻히는 닫힌 바닥, 열린 구멍 없음 | 뒷면 소실·뜬 덩어리 |

## 치수와 좌표
- 단위 m, X 동쪽·Y 높이·Z 북쪽. 남쪽(-Z)이 시작 정면.
- 정상 발판 11.3m, 태양 거울 중심 13.3m. 자세한 수평 단면은 `design-spec.json`이 유일한 원본이다.
- JSON의 일곱 높이별 12점 외곽선을 설계도와 Blender 모델이 공동으로 읽는다. 설계도에 없는 별도 원통·층을 임의 추가하지 않는다.
- 기존 H0–H9 손잡이와 P0–P5 보행점은 보존한다. 게임의 접촉면/충돌은 기존 동선 기준으로 유지하며 변경 외형과 시각 정합을 확인한다.

## 제작 순서
1. 치수 있는 정면·후면·양측·평면 투영도 생성.
2. 동일한 단면 데이터로 연속 암반 제작; 경사 전환부와 상단 모서리 침식 처리.
3. 암반에 세로 골·약한 지층·미세 광물 질감을 배치. 넓은 반복 줄무늬를 금지.
4. 정상 거울과 기존 손잡이를 연결. 북쪽·서쪽에도 실제 표면을 만든다.
5. 같은 모델을 30도 간격 12방향과 평면에서 렌더. 슬라이더로 360도 확인.
6. Unity 연결 후 등반·도약·거울·해빙 검사와 실제 화면 확인.

## 산출물 구분
- `six-view-sheet.png`: 같은 Blender 모델을 같은 축척으로 촬영한 정면·우측·후면·좌측·평면·바닥 통합판.
- `blueprint.svg`: 실제 제작 단면에서 생성한 투영 설계도.
- `review.html`: 방향별 정사영·12방향 회전 렌더 검토 화면.
- Blender 렌더와 Unity 화면의 조명/재질 표현은 다를 수 있다. 설계도는 실제 제작 형상을 기준으로 하며 AI 그림을 도면으로 포장하지 않는다.

## 360도 검토 후 보정
- 도면의 외곽선은 주 암반 기준이다. 비등반 면의 표면 요철은 약 ±0.4m, 침식골은 최대 0.72m로 추가한다. 후면/서쪽에는 몸체 안으로 묻힌 세로 암석 돌출부를 둔다.
- 손잡이 주변은 표면 변형을 제한한다. 넓은 면의 규칙적 색 띠를 없애고 작은 광물 요철 중심으로 표현한다.

## 검증 결과
- 주 암반 메시는 닫힌 단일 몸체이며 비정상 열린 모서리 0개. 외형 전체는 48,850삼각형이다. 구조 검사 근거: `geometry-check.json`.
- Blender 6면 정사영 + 30도 간격 12개 회전 렌더를 생성했다. 통합판은 Blender에서 실제 렌더를 배치해 제작했다.
- Unity 빌드 성공: `unity/MumuPlanet/Logs/cliff-design-v05.log`.
- 등반·거울·해빙 검사 133개 통과: `reports/2026-09-24/cliff-design-v05/result.json`. 기존 이동 검사도 통과했다.
- 회전 HTML은 로컬 파일로 제공한다. 앱 브라우저의 file URL 정책 때문에 자동 열기 및 버튼 UI 검증은 수행하지 못했다. 렌더 이미지 18장과 SVG 문법, 파일 경로는 확인했다.
- 기존 등반 충돌을 유지한 시각 모델 교체다. 새로 기울어진 암반의 모든 면이 새 보행 경로가 되는 것은 아니다. 실제 장치 성능과 플레이 난이도에 대한 사용자 검토는 별도다.
