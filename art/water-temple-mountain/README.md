# 물의 신전 · 태양 거울 접근 구간

> 2026-09-30: Unity 게임에서 이 돌산 구간(등반·태양 거울·해빙)을 뺐다. 물의 신전은 입구가 열린 채 바로 들어간다. 이 폴더의 원본·렌더·설계는 이력으로 보존한다. 게임 코드 보관: `unity/legacy/water-mountain-v05/`.

현재 제작 기준은 [1번 사암 절벽 시안](cliff-options-v03.png)이다. 이전 v01/v02는 제작 이력으로 보존한다.

현재 도약 구간은 **W+D를 누르고 Space를 0.35초 이상 눌렀다 놓기**다. 매달린 상태에서 W로 위, A/D로 옆, E로 올라서고 Q로 놓는다. 첫 선반과 실제 방문한 중간 쉼터에서 재시작한다.

## 플레이 흐름

1. 행성의 얼음 신전을 멀리서 발견한다. 입구는 두꺼운 얼음으로 봉해져 있다.
2. 근처 돌산의 손잡이에서 `E`를 눌러 첫 턱에 오른다. 좁은 길을 따라 올라가며 끊어진 길은 점프로 넘는다. 실패하면 마지막 안전한 턱으로 돌아간다.
3. 정상의 태양 거울을 `E`로 잡는다. `A/D`로 좌우, `W/S`로 높이를 맞추고 `Space`로 빛을 발사한다. 화면 버튼으로도 좌우 회전과 발사가 가능하다.
4. 빛을 얼음 중심에 일정 시간 유지하면 얼음이 녹고 물이 흐르며 입구가 드러난다. 이 결과는 별도의 로컬 파일에 영구 기록한다.

## 시각 설계 기준

- 등반 시작점, 좁은 돌길, 점프 간격, 정상 거울, 신전 입구가 한눈에 연결되어야 한다.
- 따뜻한 금빛 광선과 차가운 청록 얼음이 명확히 대비되어야 한다.
- 산길은 멀리서도 읽히고, 거울이 빛을 보낸 위치와 얼음이 녹는 위치가 플레이어에게 보여야 한다.

현재 Unity 구현은 행성 야외 구간과 열린 입구까지다. 물의 신전 내부 방과 상태 변화 퍼즐은 이 장면에 아직 연결되지 않았다. 참고 이미지는 최종 지형 배치·조형을 위한 미술 목표이며 실제 실행 화면과 구분한다.
