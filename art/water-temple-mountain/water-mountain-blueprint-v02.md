# 물의 신전 돌산 설계도 v02

> 2026-09-23: 현재 돌산은 사용자 요청으로 Unity 게임 장면에서 일시 제거했다. 얼음 신전 외형은 보존하고, 돌산의 등반·거울·전용 안내는 해제했다. 이 문서·레퍼런스 이미지·Blender 원본은 다음 시안을 비교할 자료로 보관한다.

기준 이미지: [water-mountain-reference-v02.png](water-mountain-reference-v02.png). 경로 그림: [water-mountain-route-v02.svg](water-mountain-route-v02.svg). 기존의 매끈한 원뿔·공중 보행로를 교체한다. 원본 이미지를 그대로 복제하는 것이 아니라, 실루엣·구간 순서·재질 대비·플레이어가 읽는 경로를 게임 모델에서 일치시킨다.

## 전체 형상

| 요소 | 게임 단위 | 이미지에서 대응하는 형태 |
|---|---:|---|
| 산 기단 | 가로 약 18m, 깊이 약 16m | 여러 덩어리가 겹친 넓은 절벽 |
| 정상 | 출발점보다 약 11.3m 높음 | 좁고 불규칙한 바위 선반 |
| 등반 얼굴 | 산 앞쪽, 절벽면에서 0.5~0.8m 바깥 | 아래쪽 손잡이·어두운 처마 |
| 등반 구간 | 손잡이 10개, 매달림 약 7m | 수직 오르기→처마 밑 횡이동→짧은 도약 |
| 발판 길 | 폭 0.9~1.3m의 불규칙한 돌 선반 | 절벽 오른쪽을 감아 오르는 좁은 길 |
| 마지막 턱 | 약 1m 위의 손잡이 두 개 | 정상 직전 점프 후 끌어올리기 |
| 태양 거울 | 정상 중앙의 석조 받침대 위 | 신전 얼음문으로 향하는 금빛 광선 |

좌표는 산 시작점 기준의 미터이며 `X=오른쪽`, `Y=높이`, `Z=산 안쪽`이다. 캐릭터 키는 약 1.5m다.

## 플레이 경로와 조작

| 단계 | 위치 `(X,Y,Z)` | 플레이어 동작 | 성공 피드백 |
|---|---|---|---|
| G0 | `(-5.2,0,-5.4)` | 손잡이 앞에서 `E` | 두 손으로 H0을 잡고 매달림 |
| H0→H1→H2 | `(-4.9,1.65,-4.72)` → `(-4.1,3.48,-4.45)` | `W` | 손·발을 옮기며 수직 등반 |
| H2→H3→H4 | `(-4.1,3.48,-4.45)` → `(-1.85,3.68,-4.75)` | `D` (`A`로 되돌아감) | 처마 아래에서 좌우로 이동 |
| H4→H5 | `(-1.85,3.68,-4.75)` → `(-1.28,4.42,-4.6)` | `W` | 다음 손잡이에 몸을 끌어올림 |
| H5→H6 | `(-1.28,4.42,-4.6)` → `(0.35,4.82,-4.45)` | `Space` | 짧은 옆 도약 뒤 반대편 손잡이를 붙잡음 |
| H6→H7→P0 | `(0.35,4.82,-4.45)` → `(1.8,5.6,-3.5)` | `W`, `E` | 바위 턱에 올라서고 일반 이동 복귀 |
| P0→P4 | 오른쪽 절벽 선반을 따라 5.6m→8.6m | 보행·일반 점프 | 발 아래 돌과 절벽의 밀착감 |
| H8→H9→정상 | `(0.4,9.65,4.0)` → `(0.1,11.3,5.0)` | `Space`, `W`, `E` | 마지막 턱을 붙잡고 정상으로 올라섬 |
| 정상 거울 | `(0.1,12.7,5.2)` | `E`로 잡고 조준 | 신전 얼음문에 빛이 닿으면 녹음 |

잘못된 방향 입력은 캐릭터를 순간 이동시키지 않는다. 매달린 상태에서 `Q`는 손을 놓는다. 추락하면 마지막 안전한 지점에서 다시 시작한다. 손잡이 간 움직임은 루트 이동과 사지 포즈가 함께 진행되어야 하며, 카메라는 절벽과 다음 손잡이가 모두 보이는 거리를 유지한다.

## 모델 제작과 검수

- Blender 원본 `.blend`와 Unity용 메시는 분리해 보관한다. 산 몸체·처마·손잡이·돌 선반의 위치는 이 표의 좌표와 맞춘다.
- 좁은 길의 시각 메시와 보행 충돌은 같은 상단 윤곽을 사용한다. 손잡이는 실제 매달림 앵커와 같은 위치에 둔다.
- 멀리서 한눈에 **시작 손잡이 → 어두운 처마 → 도약 틈 → 오른쪽 선반 → 정상**이 보여야 한다.
- Windows 실행판에서 시작·횡이동·도약·맨틀·추락 복귀·거울 조준을 직접 검증한다.

레퍼런스는 고급 환경 미술의 목표이다. Unity 실시간 조명·성능과 기존 행성 팔레트에 맞춰 재질을 조정하되, 원뿔형 산이나 공중 흰색 경사로로 되돌리지 않는다.
