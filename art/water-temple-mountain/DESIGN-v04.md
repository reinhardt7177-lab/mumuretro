# 태양 절벽 · 그래픽 재설계 v04

## 목표 이미지와 실제 제작물
- `cliff-redesign-reference-v04.png`: 내장 이미지 생성 도구로 만든 목표 시안. 실행 화면이 아니다.
- `water-mountain-v04.blend`: 편집 가능한 Blender 원본.
- `water-mountain-blender-v04.png`, `solar-altar-blender-v04.png`: 실제 Blender 렌더.
- 이전 v02/v03 파일과 원본 등반 좌표는 보존한다.

## 변경한 형태
- 직육면체를 쌓은 벽을 연속된 침식 암반으로 교체한다. 큰 암반과 세로 균열, 불규칙한 지층, 돌길 아래 지지 암반을 구성한다.
- 넓은 사각 이끼판을 제거하고 테라스의 흩어진 암석과 이끼색 군집으로 바꾼다.
- 태양 거울은 다중 청동 테두리, 방사형 눈금, 청록색 장식, 태양 광선 왕관으로 제작한다.
- 정상 제단은 석회암 단, 청동 테두리, 홈이 있는 중심 기둥, 삼각 지지대로 구성한다.

## 게임 연결
- 돌산 98,130삼각형, 제단 5,144삼각형, 회전 거울 5,676삼각형. 재질별로 묶어 내보낸다.
- v03 손잡이 10개와 보행 지점 6개, 등반 충돌 표면은 유지한다. 이전 렌더러는 숨기고 새 시각 모델을 연결한다. 새 외형 전체에 정밀 충돌을 추가한 것은 아니다.
- 거울 받침은 고정, 머리 부분만 기존 조준 축에 연결한다.
- 바위 표면 색 텍스처와 투영 UV를 함께 내보낸다. Blender의 미세 범프와 광선 추적 반사는 Unity에서 그대로 재현되지 않는다.
- 바위 삼각형 면의 방향을 내보내기 전에 재정렬하여 Unity 뒷면 제거로 지형이 사라지는 문제를 방지한다.

## 현재 품질 범위
최종 Windows 빌드 성공. `reports/2026-09-24/cliff-art-v04-final/result.json`의 등반·거울·해빙 검사 133개와 `cliff-art-v04-movement/result.json`의 기존 이동 검사가 통과했다. 최초 게임 캡처에서 발견한 암반 뒷면 제거 오류를 고친 뒤 다시 캡처를 확인했다. 성능 수치나 시안 수준의 미술 완성도를 검증한 것은 아니다.

시안은 자연광·복잡한 침식 표면·풍부한 주변 풍경까지 포함한 목표다. 이번 실제 모델은 기존 게임에 맞춘 스타일화된 형태이며, 시안과 같은 실사급 완성도로 간주하지 않는다. 신전 건물 자체는 이번에 Blender 모델로 교체하지 않았다.
