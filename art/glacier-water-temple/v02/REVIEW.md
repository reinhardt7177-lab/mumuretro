# 물의 신전 v02 — 접지와 빙하 형태 수정

## 지적 사항과 원인

사용자 스크린샷과 v01 실제 실행 화면에서 신전 밑면이 지형에 연결되지 않고 원형 판 위에 떠 보였다. 빙하는 구형 메시를 늘리고 합친 탓에 레퍼런스의 절벽·균열·얼음층 대신 둥근 덩어리로 보였다. 이동 검사가 통과했다는 사실로 외관까지 완성되었다고 판단한 것이 잘못이었다.

배치 코드는 돌산 중심의 위쪽 방향을 멀리 떨어진 신전에도 재사용하고, 신전 중심 한 점의 지면 높이만 사용했다. 구면 행성에서 건물 전체 밑면을 지형과 맞추기에는 부족했다.

## 수정한 기준

- 신전이 서는 위치의 지면 방향으로 건물을 정렬한다.
- 기초 평면은 신전 로컬 Y=0이다. 기단·계단·석주·얼음 모두 이 평면을 기준으로 둔다. 실내 바닥은 기단 상부 Y=1.1m다.
- 건물 및 빙하의 전체 부지 높이를 여러 점에서 측정해 지형이 기단을 뚫지 않도록 한다.
- 원형 판을 제거한다. 평평한 건축 부지에서 기존 지형까지 이어지는 기초 지형을 만들고, 그 메시를 이동 충돌에도 동일하게 사용한다.
- 주변 지면은 신전 바닥에 수직인 광선으로 직접 측정한다. 행성 중심 방향으로 측정한 뒤 높이만 옮기면 가장자리 오차가 생기므로 그렇게 하지 않는다.
- 기초 가장자리의 색은 실제 지형 메시의 색을 보간해서 사용한다.

## 레퍼런스에 맞춘 빙하 형태

기존 구형/타원형 얼음 생성은 v02에서 사용하지 않는다. 높이가 다른 전단 빙벽, 평평하지만 불규칙하게 깨진 상단, 지붕 위 판 모양 얼음층, 지면에서 시작하는 작은 파편층으로 교체했다. 얇은 균열과 서리 색을 더했다. 이는 레퍼런스의 실루엣과 구성 원칙을 반영한 게임용 모델이며, 이미지 수준의 사실적인 굴절과 침식 디테일을 재현했다는 의미는 아니다.

## 파일과 검증

- Blender 원본: `glacier-water-temple-v02.blend`
- 제작 렌더: `blender-frozen.png`, `blender-open.png`
- 생성 도구: `../../../tools/blender/build_glacier_water_temple_v02.py`
- 실행 증거: `../../../reports/2026-09-24/glacier-temple-v02/`
- 비교 기준: `../v01/reference.png`와 v01 실제 게임 화면. v01 원본은 보존했다.

1차 접지 검사는 최대 30.2cm 오차로 실패했다. 수직 지형 측정으로 수정한 뒤 최대 1.93cm로 통과했다. 낮은 정면·측면 시점의 실행 화면을 별도로 남겨 기초와 지형 연결을 확인한다. 테스트 통과와 미술 품질 판단을 구분한다.

최종 Windows 빌드 성공. 물의 신전 검사 140개와 기본 이동 검사가 통과했다. `water-temple-ground-front.png`, `water-temple-ground-side.png`를 확인해 기단과 얼음 하단이 기초 지형에 연결됨을 점검했다. 기본 이동 결과는 `reports/2026-09-24/glacier-temple-v02-movement/result.json`에 있다. 얼음의 사실적인 투과·굴절, 미세 침식, 신전 내부는 이번 수정 완료 범위가 아니다.
