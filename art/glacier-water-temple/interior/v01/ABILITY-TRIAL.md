# 물의 팔찌 능력 시험실

2026-09-24 · 구현 B 단계 · 최종 신전 미술과 별도

## 범위

기존 항해사와 카메라, 수첩을 사용하는 독립 장면 `WaterBraceletLab`이다. 기존 시작 장면과 빌드 장면 목록은 바꾸지 않는다. 바닥 Y=0의 작은 시험 공간에서 획득, 상태 변화, 응결과 회수의 연결을 검증한다.

## 플레이

1. 왼쪽 제단 가까이에서 **E**로 팔찌를 얻는다.
2. **F**로 팔찌 모드를 켜고 **1 가열 / 2 냉각**을 선택한다.
3. 수조나 도랑을 마우스로 가리키고 **왼쪽 버튼을 누른다**. 약 2초에 한 단계가 끝나며, 다음 단계는 놓고 다시 누른다.
4. 오른쪽 집수판을 냉각하고 수조의 물을 기화시킨다. 물이 오른쪽 집수 수조에 모인다.
5. 집수판을 준비하지 않으면 왼쪽 회수조로 돌아간다. 회수 펌프 옆 **E**로 모인 액체를 학습 수조에 돌려보낸다.
6. **N** 수첩, 오른쪽 드래그 카메라, **Escape** 팔찌 취소.

냉각판의 냉기가 유지되는 것은 이 신전의 마법 규칙이다. 물의 양은 질량에 해당하는 게임 내부 수량으로 보존한다. 실제 물리 유체 시뮬레이션이나 동일 부피를 의미하지 않는다.

## 재생성 및 검증

- Unity 메뉴: **Mumu → Build water bracelet test room**.
- Windows 생성 진입점: `Mumu.Editor.BuildWaterBraceletLab.Build`.
- 독립 실행 파일: `unity/MumuPlanet/Builds/WaterBraceletLab/WaterBraceletLab.exe`.
- 검증 실행: `unity/check-water-bracelet.ps1`. 실행 종료 코드, 검사 결과와 화면 파일 생성을 함께 확인한다.
- 최종 검증 결과는 `reports/2026-09-24/water-bracelet-lab-final`에 기록했다. Windows 실행판의 27개 검사와 정상 종료, 화면 저장을 확인했다.

## 이번 단계의 한계

- 단순 형태의 팔찌와 장치는 조작 검증용이다. 컨셉에 맞춘 최종 Blender 모델은 아직 아니다.
- 독립 시험실의 능력 상태는 세션 중에만 유지한다. 기존 완료 저장은 건드리지 않는다. 팔찌·물 상태의 영속 저장은 방 연결 단계에서 추가해야 한다.
- 도랑의 얼음 충돌 활성화는 포함하지만, 기존 평면 이동기의 바닥 기준을 바꾸지 않았다. 실제 틈을 얼음으로 건너는 이동·추락은 1실 통합에서 검증해야 한다.
- 기체 이동은 경로선으로 나타낸다. 증기·서리·낙수의 최종 연출은 후속 작업이다.
- 키는 현재 프로젝트의 직접 키보드 입력 방식에 맞췄다. 키 재지정·토글 사용 접근성 옵션·게임패드·협동은 미포함이다.
- 자동 검증과 실제 학생 플레이에서의 재미 검증은 별개다.
