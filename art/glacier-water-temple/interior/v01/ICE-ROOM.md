# 물의 신전 1실 — 얼음길 기능 구현

## 진행

1. 시작 구역 제단에서 E로 팔찌를 얻는다.
2. 1 가열을 선택하고 얼음 저수조에 왼쪽 버튼을 누른다. 녹은 물이 도랑으로 흐른다.
3. 도랑을 2 냉각으로 완전히 얼린다. 부족한 물이나 일부만 언 얼음에는 전체 길의 충돌이 켜지지 않는다.
4. 5m 틈을 얼음길로 걸어 건넌다. 반대편 안전 구역에 착지하면 왼쪽 돌다리가 내려와 고정된다.
5. 수문 가까이에서 E를 눌러 열고 통과하면 첫 방 완료다. 이번 빌드에는 두 번째 방 이동을 넣지 않았다.

## 실패와 복구

- 물 위로 걷거나 일부 녹은 얼음 위에 남으면 떨어진다. 낮은 위치까지 추락하면 마지막 안전 발판으로 복귀한다.
- 반대편 착지 전에는 시작 발판, 착지 후에는 반대편 발판으로 복귀한다.
- 물의 상태와 양은 추락 시 초기화하지 않는다.
- 잘못 기화한 물은 회수조로 모인다. 시작 구역의 회수 펌프 옆 E로 저수조에 돌려보내 다시 도랑을 채울 수 있다.
- 복귀 돌다리는 얼음이 녹아도 유지한다.

## 구현 경계

- `WaterIceRoom` 독립 장면/Windows 실행판. 주 게임의 입구·스토리·저장과 아직 연결하지 않았다.
- 첫 방만 `PlanetExplorer`의 선택적 평면 충돌 이동을 사용한다. 바닥 Y=0으로 강제 고정하지 않고 9번 레이어의 실제 지지면을 검사한다.
- 기존 행성·배·무게의 신전은 기존 이동 분기를 사용한다.
- 팔찌 입력과 물 질량 계산은 시험실 코드를 재사용한다. 시험실 장면과 이전 설계는 보존한다.
- 작은 도랑 전체가 하나의 지지 구간이다. 일부 얼음으로 중간 발판을 만드는 퍼즐은 아직 아니다.
- Blender 최종 미술, 여러 구간의 얼음길, 연출·영속 저장·협동은 후속 범위다.

## 실행과 재생성

- Unity 메뉴 `Mumu → Build water temple ice crossing`.
- 빌드 진입점 `Mumu.Editor.BuildWaterIceRoom.Build`.
- 실행 파일 `unity/MumuPlanet/Builds/WaterIceRoom/WaterIceRoom.exe`.
- 기능 검사 `unity/check-water-ice-room.ps1`.
- 같은 새 실행판에서 기존 행성 이동 검사: 위 명령에 `-MovementRegression`과 별도의 `-OutputDirectory`를 지정한다.

주 게임 장면 목록은 그대로이며, 독립 빌드에만 행성 장면을 추가해 이동 회귀 검사를 실행한다.
