# 물의 팔찌 · 웹 제작 기준

기준 시안: [기존 물방울 팔찌](../glacier-water-temple/interior/v01/bracelet-reference.png).

## 형태와 착용

- 열린 청동 커프, 청록색 표면, 금색 테두리, 물결·소용돌이 양각과 물방울 보석을 유지한다.
- 단순 토러스와 평면 보석 대신 내부 안감·후면 틈·입체 보석·곡선 조각을 만든다. 보석은 빛이 다르게 반사되는 면으로 깎는다.
- 모델 기준 반지름 0.065m, 폭 0.086m. 항해사 착용 배율은 0.58로, 반지름 0.0377m·폭 0.0499m다. 진열대는 확대된 같은 모델을 사용한다.
- 왼손 본에 붙이되 커프 중심은 손목에서 팔 방향으로 0.028m 이동한다. 보석 바깥의 발광 소켓에서 광선이 시작한다.
- 수첩 읽기·얼음 들기·점프 동작은 시전 팔 동작보다 우선한다.

## 빛과 동작

| 요소 | 기준 |
|---|---|
| 가열 | 따뜻한 금빛, 손목 → 물 방향의 잔입자 |
| 냉각 | 푸른 물빛, 물 → 손목 방향의 잔입자 |
| 광선 | 흐린 가장자리, 가는 중심, 작은 곡률. 카메라 시점에 맞는 리본 |
| 시작·종료 | 시작 약 0.20초와 지수 보간으로 점등, 약 0.67초부터 감쇠, 1.12초에 종료 |
| 물에 닿는 지점 | 보이는 표면의 부드러운 빛과 두 겹 파문 |
| 겨냥 표시 | 바닥의 옅은 원, 부드러운 점등·소등 |
| 입자 | 기본 32개, 낮음·가장 낮음 12개, 동작 줄이기 설정 0개 |

상태 변화 판정 시간은 기존 0.85초를 유지한다. 물과 얼음의 투명 재질이 광선을 깊이 버퍼로 잘라내지 않게 하되, 벽과 실제 장애물의 깊이 판정은 유지한다. 손목에서도 별도 장애물 검사를 한다.

## 원본과 실행

- 실제 게임: `src/render/WaterBraceletFx.js`에서 생성하는 웹 메시와 셰이더.
- 검수: [확대·회전 화면](preview.html).
- 보존: `model-source.json`, `enamel-patina.png`, `water-bracelet-v01.blend`, `water-bracelet-v01.glb`.
- Blender 파일은 검수한 웹 모델의 동일한 기하·재질·UV를 편집 가능한 원본으로 보존한 것이다. 웹은 Blender 파일을 직접 실행하지 않는다.
- 원본 생성: `node tools/capture-water-bracelet-model.cjs` 후 Blender로 `tools/blender/preserve_water_bracelet.py` 실행.

## 비판적 검토

기존 시안의 형태·배색·주요 문양은 구현했다. 시안에 있는 사실적인 금속 마모·환경 반사·보석 내부 굴절까지 같은 수준은 아니다. 실제 게임에서는 작은 손목 소품이므로, 과도한 발광과 표면 정보를 줄여 실루엣·착용·빛의 흐름을 우선했다. 향후 환경 반사와 마모 맵을 추가할 경우 학생 기기의 성능을 먼저 확인한다.
