# 시간의 사당 마지막 전당 · 제작 계약

앱 전체 마감의 시각적 격차를 줄이는 단계다. [목표 시안](guardian-reference.png)은 built-in imagegen으로 생성했다. 실제 웹 결과와 구분해 비교한다. [생성 프롬프트](reference-prompt.txt).

- 기존 지층 순서·낙석·표지·구슬 다섯 개·각성·마지막 구슬·귀환 로직과 저장 형식은 유지한다. 그림과 충돌이 바뀌지 않게 기존 중심·제단 위치를 사용한다.
- 전당 바닥은 y=0. 기존 신의 중심은 `(0,0,gz)`, `gz=shrine.z0+(shrine.z1-shrine.z0)*0.30`이다. 현재 배치에서는 -75.4다. 건축물 밑면과 좌대는 이 바닥에 맞춘다.
- 시안의 어두운 보랏빛 석재·겹친 로브·손·깊은 후드·별빛 얼굴·청동 천체 고리를 Blender로 제작한다. 좌대 반경 최대 5.4m, 높이 약 14m. 기존 몸체의 충돌 반경 6m 안에 주요 형태가 들어가야 한다.
- 가슴의 원형 봉인 다섯 개와 눈 두 개를 별도 이름·재질로 내보낸다. 앞선 다섯 구슬을 바칠 때 기존 상태가 같은 색으로 켜고, 복원해도 같은 모양을 보인다.
- 제단은 기존 반원 위치와 선택 범위를 유지한다. 입구의 구슬 선반과 마지막 구슬 위치를 가리지 않는다. 새 주변 기둥을 만들면 충돌·카메라 경계도 함께 맞춘다.
- 범위는 마지막 전당의 수호자·주변 석재·빛·카메라 프레이밍이다. 앞의 세 방을 이미 상세 Blender 전당으로 교체한 것처럼 보고하지 않는다.
- 필요 근거: Blender 편집 원본, GLB 실측(밑면·최고점·폭·삼각형), 시안과 실제 정면·측면 캡처, 각성/복원/보상 상태, 실제 운반·마지막 구슬·엔딩 회귀, 카메라 고체 충돌. 기능 검사 통과로 시안 수준의 재질을 달성했다고 간주하지 않는다.

## 제작 결과 · 2026-10-21

- Blender 편집 원본 `chronicle-guardian-v01.blend`, 웹 `assets/models/chronicle-temple/guardian-v01.glb` 연결 완료. 밑면 0m, 최고점 14.038m, 폭·깊이 10.797m, 19개 메시·219,204삼각형. 실제 수치는 `geometry-check.json`과 내보내기 manifest에 있다.
- 눈 2개, 발광 봉인 5개, 고정 문양 5개를 별도 노드로 내보냈다. 봉인은 바친 순서가 아닌 사당 ID와 연결하고, 재질을 공유하지 않는 어두운 문양을 봉인 앞면에 올렸다.
- 처음 문양이 흐린 원인을 ‘발광 재질에 같이 칠해짐’으로 추정했지만 Blender 구조를 확인하니 기존 문양은 별도 석재였다. 실제 원인은 로브 아래에 가려지는 위치와 작은 크기였다. 원인을 바로잡고 앞면 배치·크기·대비를 수정했다.
- 버전 1 저장의 장치 필드와 레거시 시각 노드를 보존한다. 새 모델을 비동기로 읽은 뒤와 이전 시각 스냅샷을 다시 넣은 뒤 모두 구형 몸체를 숨기고 실제 제단 상태로 봉인을 복원한다.
- 마지막 방은 높은 수호자를 볼 수 있게 시선 높이와 후퇴 거리를 조절했다. 실제 GLB 표면을 대상으로 144개 카메라 방향, 기본 시점의 발·머리·후광 프레이밍을 검사했다.
- `check-chronicle-art.cjs` 7개와 `check-strata-journey.cjs` 14개 통과. 봉인의 ID 두 개를 바꾸는 고장 주입은 색 불일치를 검출했다. 실제 이동·헌납·각성·마지막 구슬·범선 귀환·소포·끝 카드까지 확인했다.
- [시안·실제 정면/측면/후면 비교](review.html). 시안의 미세 균열·천 질감과 주변 건축 장식은 모두 재현하지 않았다. 이전 전당의 기둥·바닥·제단과 앞의 세 방을 유지하며 수호자·좌대·왕좌·조명 반응·카메라를 개선한 범위다.
