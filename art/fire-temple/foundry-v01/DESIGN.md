# 용암 주조실 · 첫 플레이 제작 기준

2026-10-20 / 기존 [전체 목표 시안](../v01/concept-overview.png)과 [전체 치수 설계](../v01/design-spec.json)를 따른다.

![주조실 제작 도면](blueprint.svg)

첫 회랑을 마치고 중앙 홀로 돌아오면 오른쪽 문이 열린다. 같은 20×26m 방의 바닥 y=0, 균열 z=-3..3, 돌길 x=26..30을 유지한다. 문·벽·장치는 전부 실제 바닥에서 출발한다.

## 보이는 경로와 조작

- 가까운 안전 바닥의 손잡이 A=(24,7), B=(31,7), 공급 밸브=(35,9). 먼 쪽에는 조작해야만 하는 필수 장치를 두지 않는다.
- 태양 문양의 먼 쪽 공급로에서 벽을 따라 폐쇄 관이 돌아온다. 열린 주조 수로의 입구는 (22.6,2.8,5.8).
- 회전 수로 A 중심=(24,2.8,5.8), B=(31,2.8,3.6). 각 수로는 서쪽과 북쪽 두 포트가 있는 ㄱ자다. 서로 다른 초기 방향에서 90도씩 돌아간다.
- A 북쪽 출구→(24,2.8,3.6)→B 서쪽 입구. B 북쪽 출구→(31,2.8,1.5)→(30.45,2.8,1.5)→틀 옆 주입구. 주입구는 폭 4m 돌길 바깥에 둬 통행을 가리지 않는다. 잘못 연결된 흐름은 닫힌 배수 홈으로 내려간다.
- 수로 바닥 높이 2.8m, 지지·가장자리 두께를 빼도 머리 위 여유 2.2m 이상. 손잡이 축과 회전 수로가 실제 연결된다.
- 틀은 깊이 6.4m·폭 4m. 바닥 -0.6m부터 용암이 차오르고, 가득 차면 표면 y=0. 공급을 닫고 4초간 가장자리부터 검은 껍질이 퍼진 뒤 걸을 수 있다.
- 먼 쪽 잠금=(28,-8). 직접 건너 잠그고 중앙 홀의 (5,8)로 돌아온다. 굳힌 길은 다시 녹이지 않는다.

## 규칙

1. 연결되지 않으면 기다려도 틀은 차지 않는다. 열린 공급 중에는 뜨거운 수로를 돌릴 수 없다.
2. 중간에 공급을 닫아도 채운 양은 유지한다. 완전히 찬 뒤 공급을 닫아야 냉각이 진행된다.
3. 다시 열면 굳기 전 냉각은 멈추고 잔열이 돌아온다. 이미 완성된 돌길은 유지한다.
4. 뜨거운 틀로 들어가거나 균열에 떨어지면 가까운 안전 발판으로 돌아온다. 수로 방향과 충전량은 유지하고 공급은 닫는다.
5. 수첩은 시간과 이동을 멈춘다. 황금 가루는 장치까지의 방향을 안내하며 방향 정답을 대신 조작하지 않는다.
6. 새로고침 시 공급은 닫힌 상태로 복원한다. 반쯤 찬 틀·굳은 길·잠금은 보존하며 안전한 체크포인트에서 시작한다.

## 원본·연결·검증

Blender 원본은 이 폴더의 `foundry-v01.blend`. 원래 전체 지도 `.blend`와 회랑 모델은 보존한다. 배포용 GLB는 `assets/models/fire-temple/foundry-*.glb`로 분리한다. 흐름·용암 표면·냉각은 웹 셰이더이며 Blender의 정적 발광 관을 실제 흐름처럼 보고하지 않는다.

두 방의 새 저장은 `mumuplanet.fire-trial.v1`에 한 번에 기록한다. 종전 `mumuplanet.fire-fracture.v1`은 읽어서 이관하고 원문을 유지한다. 본편 기록은 건드리지 않는다.

검증은 입구에서 실제 보행으로 두 방을 연속 진행한다. 잘못된 경로·부분 충전·뜨거운 틀·공급 재개·냉각·횡단·잠금·복귀·새로고침·터치를 확인한다. 검사 도구가 정답을 알고 조향하는 기능 검사와 학생의 재미 검토를 구분한다.
