# 무무 행성 집배원 (Mumu Planet Postman)

작은 구형 행성을 도는 **잔잔한 우체부 탐험 게임**. 어느 방향으로 걸어도 행성을 한 바퀴 돌아 제자리로 옵니다. 1980~90년대 한국 동네 정서 + 해변·숲·꽃밭 힐링 공간. [Messenger by Abeto](https://messenger.abeto.co/)에서 영감.

**▶ 플레이:** https://reinhardt7177-lab.github.io/mumuretro/

## 모드
- **학습 모드**(기본, `/`) — 4학년 수학 문제가 적힌 편지를 받아 **정답이 걸린 집**으로 배달.
  네비게이션은 문제 중 꺼지고 오답 2회 후에만 힌트로 열린다(안 그러면 화살표가 정답을 알려준다).
  틀려도 벌점 없음. Leitner 간격 반복으로 틀린 문제가 다시 나온다.
  **배지 14종**(끈기·배달량·실력·탐험)과 **세션 요약**(하루 목표 5문제 달성 시)이 붙는다.
  배지의 무대는 획득 순간이 아니라 요약 화면이다 — 아이들이 보상에 집중하는 건 그때이기 때문.

## 화면 규칙

기능이 하나 붙을 때마다 버튼도 하나씩 늘었고, 좌표를 손으로 찍다 보니
1280px에서 지도 버튼과 음소거 버튼이 38px 겹쳐 있었다. 그래서 규칙을 셋 세웠다.

| 규칙 | 이유 |
|---|---|
| 상시 표시는 **다섯**뿐 — 시간·지금 할 일·우상단 스택·이모지·조작법 | 나머지(도감·꾸미기·소리)는 "가끔 여는 것"이라 상시 버튼일 이유가 없다 |
| 우상단 버튼은 **flex 컬럼**에만 넣는다 (`#topRight`) | `top`/`right`를 손으로 찍을 수 없게 만드는 게 겹침을 막는 유일한 방법 |
| 색은 `:root` 변수 **다섯 계열**만 (ink·act·warm·mist·story) | 여기 없는 색을 직접 적기 시작하면 다시 여덟 계열이 된다 |

상시로 보이는 카운터는 **시련소 n/8 하나뿐**이다. 진행 축이 하나여야 아이가 "지금 어디쯤"을 안다.
우표(103)·배지(14)·Leitner 상자는 축이 아니라 그 축을 걷다 남는 기록이므로 도감과 세션 요약이 무대다.

## 특징
- **행성 크기 조절** — `src/world/Planet.js`의 `SCALE` 한 값(기본 2 = 반지름 68, 둘레 427u).
  반지름·표면 테셀레이션·콘텐츠 밀도·지형 주파수가 전부 여기서 유도된다.
- **지형 고저차** — 구면 3D 노이즈(FBM + 능선) 기반 높이장. 구역별 기복 차등(마을 평탄 ↔ 언덕 험준),
  물 영역은 해수면 아래로 함몰. `up`은 반지름 방향을 유지해 구면 보행 코어를 그대로 쓴다.
- **길 네트워크** — 구역 중심을 잇는 흙길(MST + 순환 간선). 지형에 밀착하는 리본이라 비탈에서 기울고,
  물 위 구간은 끊긴다. 길 위에는 프롭을 놓지 않는다.
- **원경 랜드마크** — 시그니처 건물(등대·풍차·탑·망원경)을 주변 국소 최고점으로 스냅.
  지평선(28u)의 2배 거리(~62u)에서 실루엣이 먼저 보인다.
- **구면 보행** — 대원(great-circle)·쿼터니언 평행수송, 극점 통과에도 안정
- **하늘** — 플레이어 up 기준 그라데이션 돔 + 뜨고 지는 해·달 + 밤하늘 별 + 저폴리 구름(인스턴싱).
  시간대 키프레임이 하늘 색·해 고도·별 밝기를 함께 구동. 총 3 드로우콜.
- **툰 셰이딩 + 외곽선**, 낮↔노을↔밤 글로벌 틴트(컬러 아틀라스)
- **밀집 한국 레트로 동네** — 주택가·상가·학교·숲을 구 전체에 배치, 수평선 컬링으로 최적화
- **배달 루프** — 비콘+화살표 네비, 우표 도감(localStorage)
- **주민·유령 메신저(가짜 멀티 프레즌스)·3D 이모지** — 멀티플레이 seam(`PresenceSource`) 내장
- **캐릭터 커스터마이즈** (머리·자켓·바지·신발·모자)
- **힐링 존** — 해변(물결 바다)·숲(연못·모닥불)·꽃밭, [Meshy AI](https://www.meshy.ai/) 3D 모델 + 절차 생성 혼합
- 잔잔한 BGM

## 커리큘럼 추가하기

과목은 파일 하나로 끝난다. `src/data/curriculum/`에 만들고 `index.js`에 등록하면
해당 구역에 자동 배치되고, 도감 총량도 저절로 늘어난다.

```js
// src/data/curriculum/korean4.js
export const KOREAN4 = {
  id: 'korean4', subject: '국어', region: 'village', emoji: '🏘️',
  questions: [
    { id: 'k1', q: "'책'의 반대말은?", a: '없음', d: ['공책', '연필', '가방'], hint: '…' },
  ],
};
```

```js
// index.js
import { KOREAN4 } from './korean4.js';
export const CURRICULA = [MATH4, SCIENCE4, KOREAN4];
```

**작성 규칙** — `validate.js`가 로드 시 콘솔에서 자동 검사한다.

| 규칙 | 이유 |
|---|---|
| 정답 **7자 이내** | 팻말 폭이 글자 수로 정해짐. 10자면 집보다 넓어진다 |
| 오답 **3개 이상** | 후보 집 4채 = 정답 1 + 오답 3 |
| 오답에 정답과 같은 값 금지 | **두 집이 동시에 정답**이 된다 |
| 설명을 답으로 두지 말 것 | `예각은 어떤 각?`(답 10자) → `직각보다 작은 각의 이름은?`(답 `예각`) |
| 오답은 "그럴듯한 실수" | 무작위 숫자면 답이 뻔해진다 |
| 힌트는 방법만, 답 금지 | 오답 2회 후 노출된다 |

구역 id: `village · temple · beach · lake · meadow · forest · hill`
