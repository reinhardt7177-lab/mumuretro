# 무무 행성 집배원 (Mumu Planet Postman)

작은 구형 행성을 걸어 다니며 **사당 여섯 곳**을 찾아 여는 게임. 어느 방향으로 걸어도
행성을 한 바퀴 돌아 제자리로 옵니다. 사당마다 과학 4학년 한 단원이 통째로 들어가 있고,
관문 셋을 지나 신전에서 그 단원의 원리를 손으로 풀면 지혜의 구슬을 얻습니다.

## 사당 여섯

과학 4학년은 단원이 정확히 여섯입니다. 억지로 맞춘 게 아니라 각 단원이 원래 서로 다른
물질과 힘을 다루기 때문에, 사당의 **색·실루엣·밝기·조작감이 저절로 갈립니다.**

| | 단원 | 관문 셋 | 신전 |
|---|---|---|---|
| **균형의 사당** | 물체의 무게 | 색 발판 · 레이저 · 무게 압력판 | 양팔저울 |
| **그림자의 사당** | 그림자와 거울 | 그림자 밟기 · 거울 셋 · 그림자 크기 | 거울을 든 신 |
| **체의 사당** | 혼합물의 분리 | 체 고르기 · 성질로 나누기 · 거름과 증발 | 체를 든 신 |
| **세 모습의 사당** | 물의 상태 변화 | 얼려서 건너기 · 미끄러운 바닥 · 세 모습 만들기 | 세 모습이 바뀌는 신 |
| **흔들리는 사당** | 화산과 지진 | 예진 · 용암 육각형 · 간헐천 | 화산을 든 신 |
| **시간의 사당** | 지층과 화석 | 층의 순서 · 내려가는 갱도 · 다섯 색의 문 | 다섯을 안고 앉은 신 |

마지막 사당은 **앞선 다섯의 구슬이 열쇠**입니다. 신전 높이 20u — 문을 지나면 천장이 안 보입니다.
구슬 다섯을 하나씩 바칠 때마다 신의 몸에 그 사당 색으로 불이 들고, 다섯 번째에 눈이 뜨면서
위에서 내려오던 빛이 꺼지고 신 자신이 광원이 됩니다. 방의 그림자 방향이 한 번에 뒤집힙니다.

## 다시 할 만한가

한 번 푼 아이가 두 번째에 손이 기억하는 대로 눌러서 끝난다면 그건 문제가 아니라 버튼입니다.
그래서 셋을 지킵니다.

**판마다 답이 달라진다** — 관문 18개 전부. 레이저의 높은 줄 위치, 압력판 주문 숫자,
거울 배치, 체 주문 순서, 밸브가 원하는 상태, 화석 코어 순서, 신전의 정답 조합까지.
장식만 흔들면 외운 답이 그대로 통하므로 **답 자체**를 바꿉니다.

**항상 풀린다** — 뽑고 끝내지 않고 뽑은 뒤 풀리는지 확인합니다. 압력판은 아예
풀리는 짝을 전부 구해 놓고 그 안에서만 고릅니다(검사가 아니라 구조로 보장).
120판씩 전수 확인: 거울 정답 없음 0 · 압력판 못 푸는 주문 0 · 체 주문마다 정답 1개.

**난이도가 오른다** — 사당 번호가 아니라 **지금까지 깬 개수**로(0~5).
어느 순서로 돌든 점점 어려워지고, 같은 사당을 다시 와도 그만큼 올라와 있습니다.
타일 생존 20→32.5초, 그림자 들키기 여유 0.75→0.47초, 갱도 낙석 예고 1.00→0.75초.
다만 예고는 0.7초 밑으로 안 내립니다 — 반응 한계보다 짧은 예고는 어려운 게 아니라 부당합니다.

시간을 죄는 건 **몸으로 푸는 관문뿐**입니다. 생각해서 푸는 방을 재촉하면 어려워지는 게
아니라 조급해집니다 — 그 방들은 대신 커집니다(압력판 숫자가 커져 상자를 더 조합해야 함).

## 화면이 말해 주는 것

프롬프트는 **가까이 갔을 때 무엇을 누를지**만 알려 줍니다. 그건 조작 안내지 목표가 아닙니다.

| | 어디에 | 언제 |
|---|---|---|
| **목표 판** | 방 왼쪽 벽 | 늘. 들어서는 순간 배너로도 한 번 |
| **힌트 판** | 방 오른쪽 벽 | 45초 헤매면 1단계, 90초면 2단계 |
| 프롬프트 | 화면 아래 | 손이 닿는 것이 있을 때 |

힌트는 **답을 주지 않습니다.** 어디를 봐야 하는지만 말합니다 — 답을 주면 그 순간
그 방은 문제가 아니라 버튼이 됩니다. 실패는 8초어치로 쳐서, 가만히 서 있는 것과
부딪히며 애쓰는 것을 다르게 대접합니다. 다시 도전하면 힌트도 처음으로 돌아갑니다.

## 지도

**길을 알려주지 않고 다녀온 것을 기록합니다.** 처음엔 온통 검고 걸어간 자리(반경 26u)만
밝아지며, 안 가 본 곳은 끝까지 검습니다. 사당도 **밝혀진 자리에 있는 것만** 보입니다 —
안 가 본 사당은 지도에 아예 없습니다. 깬 곳은 금색, 아직인 곳은 그 사당의 색.

지형 색은 세계와 **같은 함수**를 씁니다(`Planet.terrainColor`). 지도용 색을 따로 적으면
지형을 손볼 때마다 어긋나고, 아이 눈에는 "지도가 틀렸다"로 보입니다.

## 구조

```
src/
  boot.js              조립만 한다 (337줄)
  sphere/              구면 보행 — 대원 이동 + 쿼터니언 평행수송
  render/              툰 셰이딩 · 하늘 · 후처리
  world/               지형 산포 · 잔디 카펫 · 사당 겉모습
  shrine/              사당 내부 — 배치(layouts) · 조립(Room) · 관문 18 · 신전 6
  ui/                  지도 · 터치 조작
  data/lighting.js     **색은 전부 여기에만** (사당 테마 여섯 벌 포함)
  debug/introspect.js  __dbg / __selftest
```

사당 배치는 **코드가 아니라 표**입니다(`shrine/layouts.js`). 방 치수·테마·관문 종류를
데이터로 선언하고 `Room.js`가 읽어 씬을 통째로 조립합니다 — 사당을 하나 더 붙이는 데
코드를 고쳐야 한다면 그건 아직 데이터가 아닙니다.

관문의 계약은 하나뿐입니다. 열여덟 개가 전부 이걸 지킵니다.

```js
update(dt, actor, scene) → { fail? }
prompt(pos)             → string | null
solvedBy(actor)         → bool
interact(pos)           → bool     // 손으로 만지는 것만
restart() / setTier(t)             // 재도전 / 난이도
```

## 검증

눈이 없으면 장님이 됩니다. 콘솔에서:

- `__dbg` — 지형 범위 · 안개 수렴 · 후처리 · 삼각형 예산 · 컬링
- `__selftest()` — 10항목. 표면 밀착, 극점 통과, 랜드마크 가시성, 안개색 일치,
  충돌 밀어내기, 그리고 **F: 여섯 사당을 실제로 걸어서 관통**

F가 있는 이유: 구간 사각형을 각각 안쪽으로 줄여 검사하던 시절, 맞닿기만 하고 겹치지 않는
이음매마다 폭 1.0u의 **못 걷는 띠**가 생겨 아이가 첫 방에도 못 들어갔습니다.
텔레포트로 하는 검증은 이걸 절대 못 잡습니다. 방을 하나 붙일 때마다 되살아나는 종류라
상시 검사로 박아 뒀습니다.
