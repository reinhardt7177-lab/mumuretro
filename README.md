# 무무 행성 (Mumu Planet)

**초등 과학의 여섯 주제를 직접 조작하며 탐험하는 1인용 3D 웹 게임.** 작은 구형 행성을 돌아다니며 사당을 발견하고, 무게를 비교하고, 빛을 돌리고, 물의 온도를 바꿉니다. 탐험의 결과는 한 권의 수첩에 남습니다.

우주 범선에서 떠도는 소포를 회수하고 수첩을 발견하는 이야기로 시작해 **사당 6곳 · 일반 관문 17개 · 마지막 퍼즐 6개**, 채집과 요리, 귀환과 엔딩으로 이어집니다. 균형의 사당은 일반 관문이 2개이고, 나머지 사당은 각각 3개입니다. 특정 학년의 전체 교육과정이나 학습 효과를 검증한 제품이라는 뜻은 아닙니다.

**우주 범선 1차 적용:** Blender로 만든 선체·돛·황동 장치와 소포 회수, 수첩 발견, 항로 설정을 연결했습니다. [실제 화면·원본 모델·검증 보고서](reports/2026-09-09/STARSAIL_IMPLEMENTATION.md).

[기존 공개 플레이 주소](https://mumuretro.vercel.app/) · [제작자 mumuclass.kr](https://mumuclass.kr) · [이번 개선과 검증 현황](reports/2026-09-08/IMPROVEMENTS.md)

**새 탐험 구간:** 바람고개의 활공막, 능선·들길의 두 동선, 두 해법으로 여는 얼음 수로를 구현했습니다. [대표 구간 구현 보고서](reports/2026-09-08/EXPEDITION.md)

**물 사당 개선:** [비주얼 레퍼런스 01](reports/2026-09-08/VISUAL_REFERENCE.md)을 기준으로 입체 회랑·열리는 다리·흐르는 물과 중간 저장을 구현했습니다. [실제 화면과 검증 보고서](reports/2026-09-08/WATER_COURT.md)

**여섯 사당 이어하기:** 무게·그림자·분리·화산·지층에도 중간 저장을 확장했습니다. 무작위 배치, 들고 있거나 놓은 물건, 라운드와 보상을 복원합니다. [저장 확장 보고서](reports/2026-09-08/SHRINE_PROGRESS.md)

**그림자 사당 개편:** [빛과 그림자 레퍼런스](reports/2026-09-08/SHADOW_REFERENCE.md)를 기준으로 일반 관문 세 곳과 마지막 신전을 개편했습니다. [거울 회랑](reports/2026-09-08/MIRROR_GALLERY.md)은 실제 반사 광선, [그림자 밟기 회랑](reports/2026-09-08/SHADE_COURT.md)은 보이는 그늘과 일치하는 안전 판정, [그림자 크기 회랑](reports/2026-09-08/SILHOUETTE_COURT.md)은 등불·움직이는 가림판·투영 화면을 구현했습니다. [마지막 그림자 신전](reports/2026-09-08/SHADOW_SANCTUM.md)은 방향·높이 손잡이를 조합해 수호상의 실제 그림자를 맞추며, 이전 저장과 구슬 연출도 이어집니다.

> 이번 작업의 대상은 로컬 저장소입니다. 공개 주소에 같은 변경이 반영됐는지는 별도로 확인해야 합니다.

**분리 사당 개편:** [분리 사당 레퍼런스 01](reports/2026-09-08/SIFT_REFERENCE.md)을 기준으로 [체 고르기](reports/2026-09-08/SIEVE_COURT.md), [성질로 나누기](reports/2026-09-08/SORT_COURT.md), [거름과 증발](reports/2026-09-09/EVAPORATION_COURT.md), [마지막 분리 신전](reports/2026-09-09/SIFT_SANCTUM.md)까지 적용했습니다. 분리된 재료와 도구를 구별해 보여 주고, 도구 반환·이전 저장 복원·보행·모바일·구슬 획득을 검증했습니다. 후속 과제는 도구 사용 애니메이션과 처음 하는 사람의 연속 플레이 검증입니다.

**화면 설정:** 오른쪽 위 ⚙에서 자동·높음·중간·낮음·가장 낮음을 고를 수 있습니다. `?q=low`로 시작 화질을 지정할 수도 있습니다.

**최신 변경 통합:** GitHub `aed856d`의 화질 조절·끼임 방지·압력판 반환·그림자 난이도 완화를 기존 로컬 개편과 통합했습니다. [통합 결과와 검증](reports/2026-09-09/GITHUB_INTEGRATION.md).

**체질 동작:** 첫 작업장에 체 흔들기·작은 알갱이 낙하·받침 이동 연출을 추가했습니다. [영상과 42개 검사 결과](reports/2026-09-09/SIEVE_MOTION.md).

## 탐사 흐름

1. 연구실에서 소포를 열어 탐사 수첩을 얻습니다.
2. 수첩의 단서를 읽고 세 자리 다이얼을 맞춰 행성으로 이동합니다.
3. 행성을 걸으며 사당을 찾고, 각 방의 원리를 조작해서 구슬을 얻습니다.
4. 들에서 재료를 구별해 모으고, 모닥불에서 세 가지 재료로 요리합니다.
5. 앞선 다섯 구슬로 마지막 사당을 열고, 연구실로 돌아와 이야기를 마무리합니다.

수첩에는 **별·물음·들·편지·부엌** 다섯 면이 있습니다. 지도는 다녀온 곳만 밝히며, 발견한 사당과 완료한 사당을 구분합니다. 마지막 사당에서는 수첩에 기록한 표지와 색을 다시 사용합니다.

첫 언덕의 바람고개에서 접이식 활공막을 챙길 수 있습니다. 능선을 올라 활공하거나 낮은 들길을 걸어 **잠든 물길**에 도착합니다. 온열기를 얼음 가까이 옮기거나 거울빛을 흡수판으로 돌리면 같은 열 모형에 에너지가 쌓입니다. 얼음이 녹으면 물레가 돌고 기존 물 사당으로 이어지는 두 번째 문이 열립니다. 사당의 원래 위치와 진행은 유지됩니다.

이 야외 퍼즐 1개는 위의 사당 관문 17개와 별개입니다. 가 본 바람고개·물길 유적은 지도에 표시되고, 장비와 실제로 사용한 해법은 수첩 **편지 → 탐사 일지**에 남습니다.

## 사당 여섯

| 사당 | 과학 주제 | 일반 관문 | 마지막 퍼즐 |
|---|---|---|---|
| 균형 | 물체의 무게 | 무게 순서 · 무게 압력판 | 무게와 거리를 조합해 양팔저울 수평 맞추기 |
| 그림자 | 그림자와 거울 | 그림자 밟기 · 거울 세 장 · 그림자 크기 | 그림자의 방향과 길이 조절 |
| 체 | 혼합물의 분리 | 체 고르기 · 성질로 나누기 · 거름과 증발 | 혼합물과 분리 방법 짝짓기 |
| 세 모습 | 물의 상태 변화 | 얼려서 건너기 · 미끄러운 바닥 · 세 모습의 입체 회랑 | 손잡이로 온도를 바꾸고 요구한 상태 확인 |
| 흔들리는 | 화산과 지진 | 흔들림 장치 · 용암 육각형 · 간헐천 | 장치의 경고를 보며 용암 수로 연결 |
| 시간 | 지층과 화석 | 층의 순서 · 내려가는 갱도 · 다섯 색의 문 | 구슬 다섯과 제단의 사당 표지 짝짓기 |

사당은 하늘과 목적지가 보이는 **열린 섬**입니다. 내부 진행은 방과 통로를 차례로 잇는 구조이며, 테마마다 색·빛·구조물·조작이 다릅니다. 마지막 사당에서 다섯 구슬을 알맞은 제단에 놓으면 신이 눈을 뜨고 빛이 달라집니다.

물 사당의 세 번째 방은 좌우 경사로를 올라가는 3u 높이의 회랑입니다. 가까운 온도 손잡이로 상태를 맞추고 밸브를 채우면 두 회랑을 잇는 다리가 열립니다. 아래의 돌길도 계속 지날 수 있습니다. 세 밸브를 채우면 신전으로 진행하며, 구슬을 얻은 뒤에는 귀환 장치로 입구에 돌아올 수 있습니다.

흔들리는 사당의 작은 떨림·경고등·보호 고리는 **가상의 장치 규칙**입니다. 실제 지진은 작은 지진 없이도 발생할 수 있습니다. 채집의 버섯·향풀 규칙 역시 이 별의 생물을 구별하는 퍼즐이며, 지구의 식용 여부를 판별하는 방법이 아닙니다.

## 조작

| 행동 | PC | 터치 기기 |
|---|---|---|
| 이동 | WASD / 방향키 | 화면 왼쪽 드래그 |
| 달리기 · 점프 | Shift · Space | 점프 버튼 |
| 활공막 획득 후 활공 | 점프한 뒤 Space 유지 · 놓으면 접기 | 점프 버튼 길게 누르기 · 놓으면 접기 |
| 시점 · 확대/축소 | 마우스 드래그 · 휠 | 화면 오른쪽 드래그 |
| 상호작용 | E | 가능한 대상 앞에서 E 버튼 |
| 수첩 | N 또는 오른쪽 위 📓 아이콘 | 📓 버튼 |
| 지도 | M — 수첩의 별 면 | 지도 버튼 |
| 소리 | 화면의 음소거 버튼 | 화면의 음소거 버튼 |

수첩은 소포에서 얻은 뒤, 지도는 행성에 도착한 뒤 사용할 수 있습니다. PC의 수첩 아이콘에는 N 표시가 붙고, 키보드로도 버튼을 선택해 열 수 있습니다. 수첩은 보이는 닫기 버튼으로 닫을 수 있습니다. 전체 화면 버튼은 지원하는 터치 환경에서 표시됩니다.

## 중단하고 이어가기

이번 개선은 같은 브라우저와 사이트 주소에서 **이어서 탐사**할 수 있도록 진행을 저장합니다. 주기적 저장은 2초 간격이며, 주요 행동·장면 이동·페이지 종료 시에도 저장합니다. 구현과 실제 검증 결과는 [개선 보고서](reports/2026-09-08/IMPROVEMENTS.md)에 구분해 기록합니다.

저장 범위는 연구실 진행, 얻은 구슬, 채집·재료·덫, 요리 기록, 탐사 수첩, 지도 탐험과 행성 위치입니다. **여섯 사당 모두 퍼즐 중간 배치와 진행을 저장합니다.** 무작위 배치, 들고 있는 물건과 장치에 놓은 물건, 진행 라운드, 마지막 퍼즐, 구슬, 힌트와 첫 입장 난이도를 복원합니다. 여러 사당을 오가며 풀던 기록도 함께 유지됩니다.

물 사당의 녹는 얼음·미완료 미끄럼 구간과 그림자·지진·간헐천·낙석 구간은 안전한 지점에서 이어갑니다. 용암 발판은 현재 밟은 온전한 칸 가운데에서 이어가며, 이미 떨어지는 상황이면 해당 발판 구간만 초기화합니다. 다른 관문에서 풀어 둔 퍼즐은 유지됩니다. 이미 통과한 관문은 다시 지나가도 실패 판정으로 되돌아가지 않습니다.

새 야외 구간은 활공막 소유, 발견 기록, 온열기 위치·들고 있는 상태, 거울 방향, 받은 열·융해량, 열린 물길을 저장합니다. 이전 버전의 저장 기록도 읽습니다. 공중에서 중단하면 같은 지점의 지상에서 이어갑니다.

새 탐사를 시작할 때는 이전 기록 한 개를 브라우저 안에 백업합니다. 여러 저장 슬롯이나 기기 간 동기화 기능은 없습니다. 브라우저의 사이트 데이터를 지우거나 다른 주소·브라우저로 접속하면 같은 기록을 이어갈 수 없습니다. 저장이 차단된 환경에서는 화면 안내를 확인해야 합니다.

수첩 등 읽기 화면을 열면 이동과 위험 판정 시간을 멈추고, 창을 벗어나면 누르고 있던 입력을 비우도록 개선했습니다. 음소거 선택도 브라우저에 보관합니다.

## 다시 탐험할 때 달라지는 것

여러 관문에서 상자의 무게와 크기, 압력판 주문, 거울 배치, 체의 주문, 밸브 상태, 지층 순서, 제단 배치가 달라집니다. **모든 목표가 무작위인 것은 아닙니다.** 균형 신전의 왼쪽 목표는 `3kg × 2칸`으로 고정돼 있습니다.

일부 이동 관문과 압력판의 조건은 완료한 사당 수에 따라 달라집니다. 이는 게임 진행에 따른 난이도 조절이며, 학생의 개념 이해도를 평가하는 기능은 아닙니다. 풀 수 있는 주문을 고르는 구조와 내장 검사로 주요 조건을 확인하지만, 이를 모든 생성 결과·모든 기기의 완주 보장으로 해석하지 않습니다.

## 목표와 힌트

목표판과 힌트판은 열린 방의 기둥에 세워져 있습니다. 방에 들어가면 목표와 조작 안내가 한 번 표시되고, 화면 아래 프롬프트는 지금 할 수 있는 행동을 알려 줍니다.

같은 방에서 시간이 지나거나 실패하면 힌트가 단계적으로 열립니다. 첫 단계는 누적 45초를 기준으로 하며, 실패하면 힌트 시간이 8초만큼 더 쌓입니다. 힌트는 손잡이·표지·수첩 등 확인할 대상을 알려 줍니다. 여섯 사당 모두 다시 방문하거나 재접속해도 보던 힌트와 첫 입장 난이도를 유지합니다.

## 로컬 실행

별도 빌드 없이 정적 서버로 실행합니다. Node.js가 설치된 환경에서:

```powershell
node tools/serve-local.cjs 5500
```

브라우저에서 [로컬 게임](http://localhost:5500/)을 엽니다. Three.js `0.160.0`과 필요한 부가 모듈은 `vendor/three/`에서 같은 서버로 제공합니다. 엔진을 실행할 때 Three.js CDN에 접속할 필요가 없습니다. 폰트 같은 선택 자원은 외부 요청이 남을 수 있으며, 오프라인 설치 앱을 제공한다는 뜻은 아닙니다.

Python 환경에서는 기존 `python tools/serve.py 5500`도 사용할 수 있습니다.

파일이나 3D 화면을 준비하지 못하면 로딩 화면에 이유와 다시 열기 버튼을 표시합니다. 라이브러리 원본·버전·파일 해시는 `vendor/three/manifest.json`, 라이선스는 `vendor/three/LICENSE`에 있습니다.
